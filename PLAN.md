## Что изменилось (ред. 1)

- Слиты PR #30–#35, main зелёный. Проект — только мобильное приложение; вход по блокировке экрана; запросы не висят и называют причину ошибки; разделы памяти; ответ строится по порядку «память → сообщение, что не нашлось → интернет»; поиск в интернете через Tavily.

- Векторы — через `react-native-executorch` (готовые многоязычные модели), а не `llama.rn`. Требует Expo SDK 55+ и Android 13+ ([требования](https://docs.swmansion.com/react-native-executorch/docs/fundamentals/getting-started)); на старом Android поиск работает без векторов.
- План перенесён из документа и PDF в этот файл и OpenSpec.

4. **Завести поиск Яндекса** (п. 29), если нужен поиск без VPN:
    1. В [консоли Yandex Cloud](https://console.yandex.cloud) создать или выбрать платёжный аккаунт и каталог; скопировать идентификатор каталога (`b1g…`).
    2. Сервисные аккаунты → создать аккаунт с ролью `search-api.webSearch.user`.
    3. У аккаунта создать API-ключ с областью действия `yc.search-api.execute`, скопировать ключ (`AQVN…`) — он показывается один раз.
    4. PersAI → «Настройки» → «Модели и подключения» → DeepSeek → «Искать в интернете» → «Яндекс» → вставить ключ и каталог → «Проверить поиск» → «Сохранить настройки».
5. **Ответить на открытые вопросы 2–3** внизу этого файла; по желанию прислать свои вопросы о себе для набора.
