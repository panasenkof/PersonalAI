## Как поймём, что сработало

Показатели меряет проверочный набор (п. 8, [`mobile/eval`](mobile/eval)) при каждом прогоне Jest в CI. «Только слова» — поиск без индексных слов; «С индексными словами» — после подбора слов моделью (п. 12), с ответами модели из набора.

| Показатель | Только слова | С индексными словами | Цель |
| --- | --- | --- | --- |
| Находит запись по другой форме слова («машину» → «машина») | 100 % (14/14) | 100 % | ≥ 95 % |
| По синониму или связанному понятию («автомобиль» → «машина») | 38 % (3/8) | 100 % (8/8) | ≥ 80 % |
| Через человека («что любит сестра» → записи Ани) | 83 % (5/6) | 100 % (6/6) | ≥ 80 % |
| По смыслу без общих слов («чем угостить Аню» → «любит кофе») | 67 % (4/6) | 100 % (6/6) | ≥ 70 % после п. 13 (векторы — и без модели в сети) |
| Нет в памяти → помощник ищет в интернете, а не отвечает случайной записью | 100 % (3/3; было 67 %) | 100 % | 100 % |
| Записи раздела «Документы» не уходят модели | 100 % (2/2) | 100 % | 100 % |
| Лишний поиск в интернете, когда нужная запись найдена | 0 | 0 | 0 |
| Первое слово ответа без интернета / с интернетом | не измерено | | ≤ 5 с / ≤ 15 с |
| Индексация 1000 записей на телефоне | — | | ≤ 5 минут, в фоне |

Векторы и голос требуют Android 13+; считаем, что у вас 13 или новее. Главный риск теперь — размер моделей (векторы до 380 МБ, голос 150–400 МБ) и скорость на телефоне: меряем до выбора модели.
