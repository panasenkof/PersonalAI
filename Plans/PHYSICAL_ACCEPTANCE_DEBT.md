# PersAI — долг приёмки: что не проверено на телефоне и живой модели

Единый список непройденных проверок. Составлен 11.11.2026 по отметкам `NOT_RUN_PHYSICAL`, `NOT_RUN_LIVE_MODEL`, `NOT_RUN_RESTORE_DRILL`, `C2_PENDING` в [архивном снимке плана](history/PLAN_FULL_2026-11-11.md) и [реестра](history/ROADMAP_STATUS_FULL_2026-11-11.md). Целевой телефон: Vivo X200 Pro, Android 16.

**Как вести:** проверка проводится на подписанном APK с точным SHA. Результат вписывается в строку: `PASS (SHA, дата)` / `FAIL (ссылка на дефект)` / `снято владельцем (дата)`. Разрушительные проверки — только на синтетическом профиле. Отчёт о сессии — отдельным файлом в `docs/testing/reports/`.

Автоматический CI (TypeScript, Jest, браузерная проверка, сборка APK, эмулятор) для всех пунктов ниже уже зелёный; он не заменяет эти проверки.
