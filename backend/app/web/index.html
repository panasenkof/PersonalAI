Настройки помощника

Владелец сервера может настроить модель заранее. Если ответы не приходят, уточните адрес модели и ключ доступа. Облачный провайдер может взимать плату.

Приватность персональной памяти

Все внешние передачи выключены по умолчанию. Настройки действуют для будущих запросов: ранее отправленные сервисам данные невозможно отозвать с их серверов.

Сменить пароль

Остальные устройства выйдут из аккаунта. Забытый пароль можно сбросить через письмо на экране «Восстановить доступ».
