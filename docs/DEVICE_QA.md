# Приёмка PersAI на телефоне

Устанавливайте APK **поверх существующего**. Сохраните `com.paigent.app` и прежний
сертификат подписи. Не удаляйте приложение с заметками для проверки обновления.

1. **Главная.** В меню только Главная / Память / Настройки. На главной доступны
   отправка, диктовка, импорт, новый диалог и история. Отдельного Ассистента нет.
   Устанавливайте исправление на старую базу с существующими заметками: история
   должна открыться автоматически, поле сообщения — стать доступным. Не должно
   быть сообщения «Не удалось открыть историю диалогов». Обновление схемы v1 → v2
   сохраняет прежний ключ, записи, поиск и историю правок. Проверка новой установки
   отдельно не заменяет этот сценарий обновления.
2. **История и работа ИИ.** Отправьте вопрос, перейдите в Память, затем Настройки.
   Вернитесь: запрос продолжился, ответ сохранился. Во время ответа создайте другой
   диалог; первый должен закончиться независимо. Откройте его через историю.
   Кнопки «История» и «Новый чат» имеют видимые подписи; нажатие/удержание поясняет
   действие всплывающей подсказкой прямо рядом с кнопкой; системного Toast нет.
   Повторное нажатие той же кнопки подсказку не показывает, удержание — показывает.
   На узком экране и с открытой клавиатурой подсказки «Голос» и «Отправить» видны
   над кнопками, верхние подсказки — под кнопками; подсказки не закрывают нажатие
   на соседние действия. Одновременно видна одна, она исчезает через 2,5 секунды.
   Введите несколько строк → нажмите крестик внутри поля: весь черновик исчез,
   крестик скрыт, фокус остался в поле. Проверьте очистку пробелов и длинного текста.
   Начните диктовку, дождитесь текста, нажмите крестик: микрофон отключается,
   удалённый текст не возвращается. Закройте и откройте приложение: очищенный
   черновик остаётся пустым. «Новый чат» открывает пустой разговор, прежний остаётся в истории.
   Несколько раз откройте и закройте «Историю»: экран и панель не мигают.
   Полностью закройте и откройте приложение: сообщения, источники и предложения
   заметок на месте. «Стоп» останавливает выбранный запрос. Закрытие процесса
   Android может прервать запрос; при следующем входе появится сообщение об этом,
   приложение не отправляет платный запрос повторно автоматически.
3. **Одна сессия приложения.** При холодном запуске нужен вход по блокировке экрана. На телефоне только с PIN-кодом вход проходит по PIN-коду; без блокировки экрана приложение просит её включить. Переключитесь
   в другое приложение на 30 секунд и вернитесь: нового запроса нет. Повторите
   с системным выбором файла и обменом. Уйдите на пять минут: требуется вход во
   всё приложение. Отмена не открывает экраны. Открытый диалог возвращается после
   входа. В списке недавних приложений и под шторкой уведомлений содержимое скрыто.
4. **Память.** Существующие записи после обновления сохранены. Создайте раздел
   «Рецепты», добавьте запись, отредактируйте и переместите её в другой раздел.
   При открытии «Нового раздела» панель остаётся открытой, экран не мигает и не
   появляется защитная заставка; ввод и кнопка создания работают.
   Проверьте поиск, фильтр «Все записи», историю правок, события и связи. Перенесите
   запись в архив: её нет в текущем списке и поиске ассистента; верните из архива.
   Редактор открывается отдельно, выход с несохранёнными изменениями предупреждает.
   **Схема v3 (п. 11).** До установки запомните число записей в каждом разделе и
   одну-две длинные записи. После установки поверх: всё на месте, история правок и
   диалоги сохранены, поиск в Памяти находит старые записи (в том числе слово с «ё»,
   набранное через «е»). У записей из «Люди» тип «Человек», у остальных «Заметка».
   Смените тип записи и добавьте другие имена через запятую: после сохранения запись
   находится по новому имени, в истории — «Смена типа записи». Скажите помощнику
   «Запомни: Аня любит капучино» — в предложении видны тип и «о ком: Аня»; после
   «Сохранить» факт связан с записью «Аня» в «Люди» (создаётся, если её не было).
   Спросите о фразе из середины длинной записи: помощник отвечает по ней.
   Создайте в Памяти свой раздел «Рецепты», вернитесь в чат и скажите «Сохрани рецепт
   борща в раздел рецепты»: в предложении выбран «Рецепты». Попросите сохранить в
   несуществующий раздел «Гараж»: в предложении есть «+ Новый раздел «Гараж»»; раздел
   появляется в Памяти только после «Сохранить». «Документы» помощник не предлагает.
   **Слова для поиска (п. 12).** Настройки → «Умный поиск по памяти»: переключатель
   включён, через несколько секунд после запуска растёт «Готово для записей», «ждут» → 0.
   Откройте запись «Машина» — внизу «Подобрала модель: автомобиль, …». Спросите
   «Какой у меня автомобиль?» и «Что любит моя сестра?» — помощник отвечает из памяти.
   Запись из «Документов» модели не уходит: у неё нет подобранных слов. Неверный ключ
   подключения — в карточке видна причина, после исправления «Подобрать сейчас» досчитывает.
   Выключите переключатель — новые записи модели не отправляются.
   **Поиск по смыслу (п. 13).** Там же «Скачать модель · около 380 МБ» по Wi-Fi: прогресс,
   отмена работает. После скачивания «Векторы: N из M» растёт до M; запишите время на
   кусок и сколько заняли все записи (цель — 1000 записей за 5 минут). Включите режим
   полёта и спросите «Чем угостить Аню?» — помощник находит «любит капучино», хотя общих
   слов нет. Спросите о том, чего в памяти нет («Как работает фотосинтез?»): помощник
   не подставляет случайную запись и идёт в интернет — если подставляет, сообщите,
   порог близости нужно поднять. «Удалить модель» освобождает место, поиск по словам работает.
   Восстановите старую резервную копию на чистой установке: записи и поиск работают.
5. **Подключения.** Откройте Настройки → Модели и подключения. Введите два сервиса
   с разными адресами, ключами и моделями, в том числе одинакового протокола.
   Переключитесь между ними до сохранения: черновики сохраняются. «Сохранить
   настройки» активирует выбранное подключение и закрывает редактор. Перезапуск
   сохраняет оба сервиса. Смена адреса очищает только ключ этого сервиса. Нет
   настроек отдельного доступа к памяти и неактивного блока «Безопасность».
6. **Память и интернет.** Спросите о сохранённом обычном рецепте: сначала проверяется
   память. Включите интернет и выберите «Яндекс» (ключ и каталог Yandex Cloud) или
   Tavily (из России — только с VPN), спросите свежие сведения, проверьте источники. С выключенным поиском или «не используй интернет»
   поиска быть не должно. С Tavily: «Проверить поиск» в подключении показывает число
   ссылок; с неверным ключом — «api.tavily.com: ключ API не принят» или
   «searchapi.api.cloud.yandex.net: ключ не принят», без самого ключа; без роли — список, что проверить в консоли Yandex Cloud. Личные/секретные записи сохраняют свою классификацию.
   **Поиск DeepSeek.** Подключение DeepSeek → «Интернет-поиск» → «DeepSeek»: поле ключа
   подсказывает, что нужен ключ подключения. «Проверить поиск» даёт ссылки. Спросите
   «Какие новости сегодня?» — ответ со ссылками; попросите «открой первую ссылку и
   перескажи» — в строке хода видно «Читаю страницу …», нового поиска нет, пересказ
   первой ссылки из списка «Источники» под прошлым ответом. «Открой вторую» — вторая. Нулевой баланс DeepSeek даёт
   сообщение «закончились деньги», а не про ключ.
   **Свёрнутые группы.** В настройках группы «Модель», «Интернет-поиск», «Умный поиск»,
   «Голосовой ввод» сворачиваются стрелкой; в свёрнутом виде видна строка-сводка;
   после перезапуска открытые группы остаются открытыми.

7. **Голос и файлы.** «Настройки» → «Голосовой ввод». Здесь два способа: при выборе «Системное распознавание» блок «Голос без интернета» скрывается сразу и не мигает; при выборе Whisper — появляется снова, модель не скачивается заново.
   «Системное распознавание» и «Whisper на телефоне». Под ними — «Голос без интернета»
   с управлением скачанной моделью. Скачайте Whisper base → выберите Whisper.
   Несколько раз переключитесь Whisper → Системное → Whisper: модель остаётся
   скачанной, повторного скачивания и удаления нет. В каждом режиме проверьте
   диктовку в чате и редакторе заметки; после выбора системного способа должен
   запускаться он, даже если Whisper скачан. Полностью перезапустите приложение:
   выбранный способ сохранён. Явно выберите Whisper без скачанной модели:
   приложение должно предложить скачать её, без молчаливого запуска другого способа.
   При скачивании:
   виден размер и прогресс, отмена работает. После скачивания включите режим полёта
   и надиктуйте фразу по-русски. Сделайте паузу менее секунды и продолжите:
   запись продолжается. Затем помолчите примерно две секунды: микрофон выключается
   сам, появляется «Распознаю…», последняя фраза дописывается в поле. «Стоп» может
   закончить раньше. Повторите в тихой комнате, рядом с вентилятором/шумом улицы
   и с тихой речью; фон не должен постоянно удерживать микрофон или обрезать слова.
   Если после включения молчать 8 секунд, запись завершается с понятным сообщением.
   Пока кнопка показывает «Отмена» (модель загружается) или «Прервать» («Распознаю…»),
   нажатие сразу возвращает «Голос»; уже вставленный текст остаётся, микрофон выключен.
   Во время долгой диктовки интерфейс не подтормаживает (прокрутка истории, ввод).
   Системная служба определяет конец речи сама, время паузы зависит от телефона.
   Смените диалог во время записи: его черновик не должен получить старую диктовку.
   Повторите очистку/уход с экрана, пока модель загружается или открыто разрешение
   микрофона: запись не должна запуститься позднее. «Удалить модель» освобождает место; для дальнейшей диктовки выберите системное распознавание.
   Диктовка заполняет черновик без автоматической отправки.
   На первом запуске окно разрешения микрофона не должно отменять диктовку: после
   разрешения появляется «Слушаю». «Использовать системную службу» спрашивается
   один раз за сеанс. Любая неудача показывает службу, причину и код.
   Проверьте отказ в микрофоне и повторный запуск. TXT читается на телефоне.
   Изображение/видео передаётся провайдеру только после выбора внешнего
   разбора файла. Просмотрите и исправьте результат перед сохранением. Аудио
   распознаёт скачанный Whisper на телефоне; изображение требует vision-модели, видео анализируется
   по пяти кадрам, без звуковой дорожки.
8. **Клавиатура, панели, системные кнопки.** На узком экране откройте клавиатуру
   в главном чате, редакторе записи, поиске истории, названии раздела, модели и
   импорте. Ввод, «Отправить» и «Сохранить» видны или доступны прокруткой.
   Проверьте небольшой экран, большой системный шрифт, жестовую навигацию и режим
   трёх кнопок Android: нижние действия не перекрыты системной полосой. Панели
   истории, разделов и вложений не уходят под клавиатуру; «Назад» сначала закрывает
   клавиатуру/панель, затем возвращает на экран. Шторка уведомлений не отменяет ИИ.
9. **Резервные копии.** Отдельный экран доступен из Памяти и Настроек. Создайте код,
   сохраните его отдельно, экспортируйте копию. На пустом другом профиле/телефоне
   восстановите записи и диалоги, проверьте отказ с неверным кодом. Старые копии
   без диалогов продолжают восстанавливать память. Существующие диалоги и записи
   не перезаписываются. Во время активного запроса восстановление недоступно.
10. **Обновление со старой версии с серверным входом.** Установите новый APK поверх
    версии, где был выполнен вход в серверный аккаунт. Приложение открывается без экрана
    входа, прежние записи и диалоги на месте, запрос адреса сервера не появляется.
    Повторите с версией, где использовался режим «на телефоне» без аккаунта.
11. **Нативное шифрование SQLCipher.** Файл базы не начинается с заголовка
    `SQLite format 3\0`; обычный SQLite не открывает его без ключа. Отмена входа
    не показывает ни одного экрана. После входа переходы между вкладками не требуют
    повторной биометрии. Проверка в CI собирает APK, но не доказывает шифрование
    во время работы — результат приёмки на устройстве нужно записать.

12. **Первый запуск и модели.** На новой установке главная предлагает выбрать сервис.
    Выберите YandexGPT, вставьте ключ, замените ID каталога, нажмите «Проверить связь»:
    приходит ответ модели. Неверный ключ даёт понятную ошибку без текста ключа.
    Повторите с DeepSeek и с локальной моделью в домашней сети. Ответ появляется
    по частям; «Стоп» во время ответа останавливает его. Длинный ответ на модели с
    рассуждением не заканчивается ошибкой.

Автоматически проверяются TypeScript, регрессии, реальные SQL/FTS/транзакции
через Node SQLite, обновление сохранённой схемы v1 (обе выпущенные формы), откат
неудачного обновления и повторное открытие истории. Интерфейс на 320/390/768 px
использует production App и настоящие навигаторы, имитацию Android Dialog blur/focus,
системные отступы 0/24/48 px и уменьшенную высоту окна. Также проверяются
JS/Hermes Android+iOS и Android signing configuration. В браузере
нативные службы и SQLCipher имитируются; проверка на реальном телефоне необходима
для биометрии, SQLCipher, системной клавиатуры, picker и аппаратных кнопок.
