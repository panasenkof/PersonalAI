# Приёмка исправлений PersAI

Устанавливайте обновлённый APK **поверх существующего**, сохранив package
`com.paigent.app` и прежний сертификат подписи. Не удаляйте приложение с
заметками для проверки обновления. Автоматические тесты не заменяют проверки
SQLCipher, аппаратной биометрии и службы речи на вашем Android.

1. **Один вход.** Разблокируйте приложение. Откройте Память → Ассистент → Память
   три раза. Второго запроса биометрии для памяти не должно быть. Сверните
   приложение: после возвращения нужен вход во всё приложение. Отмените
   вход: заметки, ключи и беседы не должны быть видны.
2. **Сохранение заметок.** Создайте заметку, исправьте её, закройте приложение
   полностью и откройте снова. Содержимое и версия должны сохраниться.
   Проверьте прежние заметки после обновления и поиск по ним.
3. **Подключения.** Заполните два подключения разными адресами, ключами и моделями.
   Переключайтесь между ними до сохранения: введённые данные остаются.
   Выберите активное, нажмите Сохранить: откроется предыдущий экран.
   Откройте настройки снова и перезапустите приложение: оба подключения на месте.
   Смена адреса очищает ключ только редактируемого подключения.
4. **Память → интернет.** Разрешите модели чтение обычных заметок. Спросите о
   сохранённом рецепте: сначала проверяется память. Выберите «Без регистрации
   (Bing)», включите интернет, спросите свежие сведения: проверьте ссылки.
   С отключённым поиском и с фразой «не используй интернет» поиска быть не должно.
   Если публичный сервис заблокирован, приложение должно сообщить об ошибке.
5. **Диктовка.** Нажмите микрофон, произнесите текст. Он появляется в поле,
   отправка выполняется отдельным нажатием. Проверьте отказ в доступе к микрофону,
   остановку и повторную диктовку. Если русский офлайн-модуль отсутствует,
   доступен явный выбор системной службы; без вашего выбора сетевого перехода нет.
6. **Файлы.** Импортируйте TXT без внешней передачи. Для изображения/аудио/видео
   отдельно выберите обычные данные, подключение и действие разбора. До этого
   файл не должен уходить провайдеру. Просмотрите и исправьте результат,
   подтвердите сохранение. Для аудио нужен STT-совместимый endpoint; для изображения
   — vision-модель. Видео даёт пять кадров по длительности, без разбора звука.
7. **Резервная копия.** Блок сначала свёрнут. Раскройте, создайте код и сохраните
   его отдельно. Проверьте экспорт и восстановление в пустую память другого
   профиля/устройства, включая отказ с неверным кодом. Возврат из системного
   выбора файла/обмена не должен вызывать сбой закрытого соединения.
8. **Внешний вид.** Проверьте значок на рабочем столе с круглой и квадратной
   маской, иконку внутри приложения, светлый/тёмный режим, клавиатуру,
   небольшой экран и увеличенный системный шрифт. Символ не должен обрезаться.

Локально автоматизировано: TypeScript, unit/regression tests, production-screen
browser scenarios на 320/390/768 px (нативные службы в них имитируются), веб/PWA
на 320/390/768/1440 px, Expo зависимости/Android prebuild и JS-экспорт Android/iOS.
Нативный APK компилируется отдельным GitHub Actions workflow на PR. Факт его
сборки не доказывает работу шифрования или биометрии на телефоне.
