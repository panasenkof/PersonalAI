## Что относится к готовой дизайн-системе

- **Сделано к 22.10.2026:** typed tokens, базовые компоненты, политика состояний, Skia B+C и Home-only theme, живой Home, A/B и стабилизация в #96. `src/theme.ts` уже изменён для Home.

## Дизайн-токены

- Файл `mobile/src/design/nebula/tokens.ts` — **единственный источник** токенов компонентов Nebula. Не захардкоживать `#...` в новых экранах вне токенов/рисовального кода.
- Семантика: `canvas, surface, surfaceElevated, surfaceMuted, border, text, textSecondary, accent, cyan, electric, focus, success, warning, danger`; dark и light равноправно проверяются на WCAG AA. Яркий световой ореол/«орб» — **арт-слой**, а не фон текста.
- Сетка 4dp, основные шаги 8/12/16/20/24/32/40dp, размеры под касание **не менее 48×48dp**, визуальная иконка может быть меньше при большой интерактивной области.
- Текст: системный scaling не принудительно запрещать; типографика набирается ролями, заголовок 24/32dp, основной текст 16/24, подпись 13/20.
- Компоненты растут по содержимому; запрет фиксировать высоту текста/карточки так, что русский текст 1.5× вылезет за границы. В composer ограничить **высоту поля ввода** и скроллить его, но не обрезать текст.
- Dark Nebula — бренд по умолчанию только **после отдельной миграции**, до неё хранить настройки темы и не ломать существующие светлые экраны. Light/high contrast поддерживаются.

## Размещение и IA

| Экран | Главное пространство | Второстепенные действия |
| --- | --- | --- |
| Главная | Виртуализированная история + закреплённый ввод | Компактные история/модель; `+` открывает медиа bottom sheet; «Улучшить/Исходный» сохраняется |
| Память | Поиск, заметки, короткие фильтры | Отдельное добавление; batch actions только в режиме выбора, экспорт/копии в настройках |
| Настройки | 6–8 коротких пунктов категорий | Детальные формы по вложенным маршрутам |
| Будущие automations/LLM tools | Контекстный доступ из чата и настройки | Не создавать новый bottom tab без отдельного UX-решения |

Вложения в диалог **не равны** сохранению в память. До отдельной OpenSpec запрещено строить фиктивный multimodal UI, отправлять приватные файлы LLM, утверждать что фото/PDF уже анализируются.

**Утверждено дополнительно:** [B+C для NebulaCore](design/NEBULA_HYBRID_BC_DECISION.md). Визуальные PR обязаны сохранять художественную детализацию B при добавлении динамики C. Реальный Skia-кандидат принимается только по [Android QA](design/NEBULA_SKIA_LAB_QA.md), а не по факту зелёного TypeScript.

## Анимация и доступность

- `mobile/src/design/nebula/motion.ts`: единый контроллер разрешений анимации, не источник истины о вызове LLM/микрофоне.
- 7 фаз: idle, listening, transcribing, thinking, responding, offline, error. Незавершённое / ошибочное состояние **явно подписывать словами**, не только цветом.
- `reduceMotion=true`, `appActive=false` → качественный статичный **REF-ORB-B**, без звёзд/бесконечного эффекта. `powerConstrained` → reduced mode; star-flight только отдельное разрешённое событие при idle, **не на каждое сообщение**.
- Нельзя выдавать PNG со scale/rotate за завершённый NebulaCore. Для high-fidelity рендера требуется измеренная native R&D: Skia/шейдеры против высококачественной последовательности кадров; ограничения описаны в [motion spike](design/NEBULA_MOTION_SPIKE.md).

## Инварианты для каждого PR

1. Проверить референс и эту спецификацию **до правок**; отсутствующие бинарники — блокер визуального принятия.
2. Сперва просмотреть архитектуру компонента, reuse и входы будущих функций; новые роуты — только при UX-обосновании.
3. Не изменять поведение SQLCipher, отправку LLM и Android-разрешения под видом дизайн-рефакторинга.
4. Проверить 320/360/390/430dp, уменьшенную высоту, Android gesture/3-button, реальные insets/клавиатуру, **не только браузерную имитацию**.
5. Обязательно состояние: пусто/загрузка/ошибка/нет доступа/отмена; длинный русский текст 1.0×,1.3×,1.5×; dark/light; TalkBack; доступность touch.
6. Снимки до/после; визуальные артефакты не подменять скриншотами «как будто UI»; эталон менять только с ревью.
7. Тесты чистых токенов/политик отдельно от natively-driven animations; `npm test`, `npm run typecheck`, `npm run test:ui`, APK smoke. Каждый результат записать, **если не запускали — явно сказать**.
8. Для производительности: FPS p50/p95, загрузка памяти, батарея/нагрев, AppState, Android Reduce animations, остановка анимаций в background.
9. Присылать автору diff/сравнение с оригинальным изображением, матрицу сценариев и список **ещё не реализованных функций**.
10. Если технически не удаётся получить то же качество, нельзя самостоятельно «упростить». Нужны spike, измерения и новое решение владельца.

## Критерии готовности задачи 88

- Все общие компоненты имеют токены, light/dark и доступность; нет независимых цветов/радиусов в новых страницах.
- Разделы Home/Memory/Settings переиспользуют базу, а не копируют стили.
- `NebulaCore` получает фазу из операций, не подменяет её «случайным пульсом».
- Нативный прототип иконки/орба сравнен с оригиналами; реальная Android проверка и performance.
- UI-проверки добавлены в PR gate и root `AGENTS.md` ссылается на этот документ.

### 22.10.2026 — дополнительное соглашение по сферам Skia

Для Nebula Lab необходимо соблюдать [фазовые неоновые нити и диагностический ×5](design/NEBULA_STATE_FILAMENT_SPEC.md): исходная B+C-плазма и фон без упрощений, контур совпадает с органической формой, в `idle` нити нет, у шести других фаз — собственный цвет и ритм (offline/error цветные, но статичные). Новые uniform-значения и качество графики проверяются отдельно от состояния LLM/микрофона. Нативная художественная приёмка остаётся за владельцем.


### Nebula dual-motion tuning (22.10.2026)

Соблюдать [NEBULA_DUAL_SPEED_THINKING.md](design/NEBULA_DUAL_SPEED_THINKING.md): основной живой orb ×5, независимые эффекты контурной неоновой нити ×1, нить привязана к тому же органическому краю. Thinking: ограниченное увеличение деформации (+~20%) и пульсации без увеличения частоты. Лабораторное сравнение ×1 не является рабочей скоростью и не должно переноситься в production. Не менять оригинальную графику или космический фон. При Reduce Motion / offline / error и свёрнутом приложении анимации останавливаются.
