## №66.1 / M10: согласованный результат enrichment

Подтверждено: `direct-agent/enrich.ts` сохранял ответ без проверки `record_version`; слова и связи записывались раздельно. Очередь сравнивала timestamps, поэтому правка в ту же миллисекунду могла считаться обработанной. Контекст запроса содержит название коллекции, не только текст заметки.

Решение: атомарная проверка версии/коллекции/доступности и запись результата; отмена до commit откатывает всё. В schema v6 добавить nullable версию источника и название коллекции к модельным словам. Старые строки не считаются проверенными: исходные заметки/ручные слова сохраняются, модельные слова ставятся на повторную обработку. Проверять миграцию с откатом; не менять ключи SQLCipher. Новые автоматические связи получают provenance, ручные не удаляются. Старые связи с `source_kind=NULL` неотличимы от ручных: не делать массовую очистку по догадке; полноценный пересмотр — №66.4.
