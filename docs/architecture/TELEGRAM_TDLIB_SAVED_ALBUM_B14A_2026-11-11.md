# Telegram TDLib B14A — безопасное распознавание альбомов «Избранного»

Дата: 11 ноября 2026. Статус CODE_CANDIDATE / CI_PENDING / NOT_RUN_PHYSICAL.

## Почему нужен отдельный этап

TDLib отдаёт `message.media_album_id` как int64, а JS Number теряет точность за 2^53. Необходимо передавать идентификатор строкой, прежде чем изменять writer или загружать оригиналы группы.

`getChatHistory` и `getSavedMessagesTopicHistory` отдают сообщения в обратном хронологическом порядке и ограниченной страницей. Последняя позиция текущей страницы не означает завершение альбома, поэтому нельзя формировать «полную» заметку из одного хвоста. Группа в Telegram имеет максимум 10 вложений; её принадлежность определяется строгим строковым совпадением `albumId` и self chat, а не близостью времени или совпадением подписи.

## B14A

- В существующей нативной проекции Saved Messages добавить только необязательный `albumId`, строкой, если `hasAlbum` истина. Не отдавать сырые TDLib сообщения, контакты, file_id или URL.
- Валидировать идентификатор без преобразования в JS Number.
- В едином read-only планировщике `planSavedAlbum` отдавать `ready` только после подтверждённой границы более старого сообщения либо десяти элементов; на границе страницы возвращать `pending`, на перемежающихся ID — fail-closed.
- В этой фазе **не скачивать**, не сохранять и не подтверждать альбомы. Импорт текстов и одиночных оригиналов не изменяется.

## Следующий этап B14B

- Для `pending` читать ещё одну ограниченную страницу истории, сохранять совместимый cursor и не пропускать часть группы.
- Нативный download каждого оригинала только из явно обнаруженного в собственном чате альбома, сопоставление albumId/messageId/date/caption.
- Один canonical `saveMediaNote(files)`, строго типизированный список source IDs, stable album receipt и дедупликация между общей историей и подборками.
- При ошибке загрузки любого оригинала — никакой частичной заметки. Управляемая очистка TDLib-кеша через тот же узкий нативный мост.
- Только после зелёного CI и отдельной ручной проверки считать альбомы доступными пользователю.

## Инварианты

C0-A / C3-B: существующие TDLib gateway, SQLCipher writer, AppLock, темы, receipts, индекс; нет второго хранилища, отдельного file writer, сервера и нового LLM-обхода.
