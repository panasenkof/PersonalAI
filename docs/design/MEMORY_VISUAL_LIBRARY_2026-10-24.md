# Память: визуальная библиотека и редактор заметки

Владелец 24.10.2026 запросил перепроектирование памяти с плитками и фотографиями,
упрощение страниц записей и редактирование голосом/LLM. После макетов: «Согласен, делай».
Рабочий выбор — коллекции + недавние записи (третий макет) и показанный экран ИИ-правки.
[Библиотека](references/memory-20261024/library-target.png),
[ИИ-редактор](references/memory-20261024/note-ai-target.png) — визуальные цели, не скриншоты APK.
Исходный REF-UI-C и токены Nebula сохранены. Сфера и Home не меняются.

## UX-контракт

- M1: Память → поиск, коллекции с обложками, сетка недавних записей. Свои
  недавно использованные коллекции получают приоритет над пустыми встроенными.
  Доступ ко всем коллекциям и созданию — «Все». На 320dp/при шрифте ≥1.4 — один столбец.
  Переключатель списка доступен независимо. Заголовки не перекрывают фотографии.
- M2: Нажатие карточки открывает чтение. Долгое нажатие — массовый выбор.
  Архив/корзина/копии/импорт — меню памяти. Перенос, объединение, восстановление и undo сохранены.
- M3: Страница записи показывает содержимое и оригиналы, а не анкету.
  «Редактировать» открывает текст и диктовку. Заголовок необязателен, fallback — первая строка.
  Раздел наследуется при создании; тип по умолчанию зависит от раздела.
  Алиасы/ручные слова поиска доступны, но не обязательны; индекс/даты/данные файлов — автоматически.
  OCR/оригиналы и история не переписываются ИИ-редактором.
- M4: «Изменить с ИИ» → текстовая/голосовая команда → явный запуск → предпросмотр,
  сравнение с исходным → применение к черновику → отдельное сохранение.
  После применения доступна отмена правки. Автосохранения ответа LLM нет.
- M5: Отмена, уход, блокировка/фон отменяют запрос. Поздний ответ не применяется.
  Изменившийся черновик нельзя затереть старым ответом. Диктовка и Save не конкурируют.

## Данные и LLM

Один ограниченный helper-запрос через существующие подключения OpenAI-compatible/Anthropic,
без agent loop, истории чата, поиска, инструментов или других заметок. Передаются только
команда, заголовок и body (при пустом body — видимый распознанный текст).
Результат применяется к body; исходная расшифровка остаётся отдельной. Приватные/неопределённые записи и коллекции не отправляются;
`inherit` разрешён только внутри standard. Несохранённый перенос из закрытой коллекции
не расширяет доступ. Лимиты: 16 000 символов записи, 2000 команды, 24 000 результата.
Обрезанный/невалидный ответ отклоняется без автоматического повторного запроса.
Сохранение использует существующий version check и историю; индекс обновляется штатно.

## Превью

Только локальные вложения. Не загружать remote-обложки и не отправлять фото модели ради плитки.
Видимые карточки: максимум две параллельные задачи, изображение ≤12 МБ, resize до 480px,
временный JPEG в очищаемом `persai-previews`. Оригинал удаляется из временного просмотра
после resize; миниатюра — при уходе, блокировке, фоне, размонтировании. Поздний decode
после отмены удаляется. Никаких миграций SQLCipher или незашифрованного постоянного индекса.
PDF/видео без картинки показывают тип и текст: настоящие PDF thumbnails/видеокадры
пока не реализованы, не подменяются демонстрационными фото. Фото >12 МБ доступны через
существующий явный viewer, автоматическая обложка для них не декодируется.

## Проверка

- Jest: запросы, конфиденциальность, лимиты, cut-off, отмена/late response, preview/apply,
  конфликт черновика, lifetime thumbnail и лимит параллелизма.
- Browser production screens: сохранение и повторное открытие, параметры/алиасы,
  история, архив и возврат, поиск, import; актуальные пути через меню и режим чтения.
- Обязательный Android CI остаётся minimal.yaml. Расширенный smoke актуализирован,
  но не возвращён в обязательный gate. Нативная диктовка, SQLCipher thumbnail decode,
  IME, TalkBack и приёмка внешнего вида на физическом телефоне — отдельная проверка APK.

Референсы UX: https://mymind.com/ (визуальные типы карточек), https://raindrop.io/
(коллекции, сетка/список). Это ориентиры взаимодействия, не зависимости приложения.

Фактические проверки и ограничения: [QA](MEMORY_VISUAL_LIBRARY_QA_2026-10-24.md).
