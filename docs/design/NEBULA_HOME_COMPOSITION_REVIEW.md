# PersAI Nebula · Home v0.3 — интерактивная композиция и сценарии

**Этап 86 · для согласования компоновки.** Сфера B+C уже художественно утверждена владельцем; данный макет **не меняет** ни её детали, ни скорости core ×5 / filament ×1, ни реальные функции приложения.

## Прототип

[Открыть HTML-макет](../prototypes/nebula-home-composition-v03.html). Файл локальный: после `git clone` или загрузки дерева проекта открыть `docs/prototypes/nebula-home-composition-v03.html` в браузере. Исходная сфера подтягивается из соседней папки `mobile/src/design/nebula/assets/nebula-orb-ref-b.png`; **не скачивать только один HTML в пустую папку**, иначе картинка будет недоступна. GitHub может показывать исходный код вместо исполнения — это ограничение предпросмотра GitHub, а не ошибка прототипа.

### Что можно переключать

- Три состояния: **Новый чат**, **Диалог**, **ИИ думает**.
- Экранная ширина **320/360/390/430 dp**.
- Фокус на настоящем текстовом поле, который **на телефоне** открывает установленную системную клавиатуру Android. Никакой собственноручно нарисованной клавиатуры: браузер на компьютере не воспроизводит native IME.
- По **+** — меню «Изображение», «PDF», «Аудио», «Камера», чипы вложений и удаление чипа до отправки.
- Отправка тестового текста добавляет подпись **«Демонстрация, не отправлено»**. Микрофон/LLM, память, OCR, транспорт и работа с файлами **не вызываются**.

### Что необходимо оценить глазами

1. Чат занимает больше полезной площади, чем старая шапка / приветствия. Нет «Чем помочь сегодня?» и длинных технических надписей.
2. **Empty state:** оригинальный сложный REF-ORB-B заметен, но не выдавливает поле ввода и нижнюю навигацию. Реальная Skia-анимация будет только в Android.
3. **Active state:** компактная статусная сфера рядом с контентом, читаемые контрасты, свободная прокрутка сообщений.
4. Header: бренд, модель, история, новый чат — одна компактная строка, понятные accessibility labels.
5. Composer: «+» / поле / микрофон / отправка, «Улучшить/Исходный» в соседней компактной строке. При длинном тексте поле расширяется ограниченно и внутренне прокручивается.
6. Настройки/Память пока остаются нижними вкладками **без полноценного редизайна** на этом этапе; будущие automations, медиа и агенты не создают новые обязательные вкладки.
7. На 320dp контролы не должны вылезать за края. Кнопка «Открыть ввод (системная клавиатура)» лишь переводит фокус на поле; на реальном телефоне используется выбранная в Android IME. Не рисовать фальшивые клавиши; проверять настоящие Android `WindowInsets`, `adjustResize` и поведение системной навигации в APK.

## Строгие ограничения для реализации

Это макет композиции, а не React Native код. Нельзя переносить в производство действия `alert()` или демонстрационные ответы как реальные функции. В текущем приложении уже существуют истории диалога, профили моделей, голос/нормализация, зашифрованная память, share, импорт и адаптеры. UI-миграция должна **сохранить их** и привязывать status только к настоящим фазам операции.

Не заменять REF-ORB-B на flat SVG или generic circle; использовать [approved orb](NEBULA_DUAL_SPEED_THINKING.md) через безопасный production adapter с режимами reduced-motion, background и feature flag.
