# PersAI Nebula — художественное решение B + C (APPROVED)

**Решение владельца продукта от 21.10.2026. Статус: УТВЕРЖДЕНО как художественная цель.**
В текущем исследовательском PR технология **НЕ** утверждается автоматически: прежде нужен нативный Android proof и сравнение с образцами.

## 1. Неизменяемая формула

> **B даёт детализацию, объём, насыщенность, стеклянно-плазменные многослойные материалы и космический фон; C даёт внутреннюю живую динамику, движение световых мембран, мягкий органический morph и отклик на события.**
>
> Финал — гармоничный *гибрид B+C*. Не заменять «либо B, либо C», не превращать его в обычный пульсирующий круг.

Оригинал: `REF-ORB-B.jfif` в [неизменённом ZIP](references/README.md), SHA-256 `4533219948abbb7deace795da0d391c849d88874e014cbd8795a02d455b2a914`. Полная иконка приложения остаётся основанной на **REF-ICON-A** (другая оригинальная картинка), ее не подменять screenshot/orb.

Изображения и сравнение B/C, согласованные в беседе 21.10.2026, — **референсы**, а не утверждённая библиотека / код. UI приложения остаётся Nebula с полноэкранным чатом, вложениями, голосом и спокойным звёздным фоном.

## 2. Нормативные характеристики визуала

| Качество | Приёмочный критерий | Нельзя |
| --- | --- | --- |
| Форма | Объёмная сфера с нерегулярной, но плавной динамической границей (несколько частот, амплитуда умеренная) | ровный пульс/масштабирование PNG без формы |
| Материал B | Внутри различимы **не менее 3** полупрозрачных сложных мембран/линз, глубокие стеклянные блики, насыщенный циан/фиолетовый | один radial gradient или плотный бесцветный шейдер |
| Движение C | Мембраны движутся с *разными скоростями/фазами*, плавают caustics и энергия внутри, нет скачков на зацикливании | резкое и быстрое «желе», кручение всей сферы одинаково |
| Свет | Бело-циановая энергия внутри, фиолетовый ободок и мягкий halo без мерцания/вспышек | постоянный агрессивный glow за текстом |
| Фон | Звёзды, глубина, туманности и умеренный параллакс; короткий star-flight лишь при запуске/новом чате | непрерывный гиперпространственный пролёт за длинным ответом |
| Контекст | В большом виде — только пустое состояние/эксперимент; малый avatar не мешает чату | сфера перекрывает composer, потоковый ответ, медиа |
| Доступность | При Reduce Motion / background / low power — **качественный статичный REF-ORB-B**, плюс словесный статус | исчезновение индикатора/подмена круглой заглушкой |
| Производительность | На реальном устройстве снимать FPS p50/p95, энергию, память и нагрузку при 44/168 dp | объявлять победителя только по web preview/CI green |

**Порядок приоритетов:** максимальное сходство художественного уровня с B, затем естественное движение C, затем скорость; при нехватке производительности обсудить переход на подготовленные кадры и уменьшение качества анимации, но **не заменять изображение произвольно**.

## 3. Техническое сравнение: Skia vs video

**Skia — основной экспериментальный кандидат**, а не автоматически финальная технология. План:
1. `NebulaSkiaExperiment` в изолированном модуле на Expo SDK 57 + RN 0.86, Skia 2.6.2 + Reanimated 4.5.1 / Worklets 0.10.1.
2. Выполнить image-backed RuntimeEffect: REF-ORB-B остаётся базовой художественной текстурой; SkSL добавляет живое поле рефракции, 3–5 мембран и сложные блики, не сводясь к одному круговому градиенту.
3. Использовать фактические статусы `resolveNebulaScene` (idle, listening, transcribing, thinking, responding, offline, error), foreground и Reduced Motion; никакого воображаемого уровня микрофона.
4. Сопоставить с видео-кандидатом `NebulaVideoExperiment` (экспериментальная ветка `feat/nebula-native-motion-candidate-20261021`, может быть ещё не слита).
5. Показать владельцу два видео по одинаковому исходному референсу; получить оценку качества/динамики, а **потом** решать о включении на главной.

**SDK57 caveat:** проблема `makeImageFromView` при Skia 2.6.2 / RN 0.86 (expo/expo#50733), проверка shader **не должна** использовать `makeImageFromView`. Это отдельный известный дефект screenshot API, не доказательство общей неработоспособности GPU-шейдеров. Упрощения / обновление до неподдерживаемой Skia версии без проверки запрещены.

**Текущий статус исследования:** оригинал ZIP подтверждён; браузерный и видео-кандидаты исследованы; нативный Skia B+C кандидат будет добавлен отдельным PR; реальные кадры с Android, измерения FPS/памяти/энергии и художественная приёмка пока **не проведены**.

## 4. Не смешивать готовность

- **Утверждено:** что должно выглядеть и двигаться как B+C, ограничения UX и две роли оригинальных изображений.
- **В процессе:** Skia shader-кандидат, статичный постер/адаптер, QA сценарии и CI.
- **Не готово:** финальная Figma v0.3, конечные фирменные эффекты на всех экранах, официальный production `NebulaCore`, реальная пользовательская оценка 2 рендеров на Android и миграция Home.
- После CI прогнать *release APK* с test lab, опубликовать видео side-by-side и записать результаты.
