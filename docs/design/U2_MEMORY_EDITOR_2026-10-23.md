# U2 — редактор заметки: фокус на содержимом

23.10.2026 · нормативные основания: [Nebula Visual Contract](NEBULA_VISUAL_CONTRACT.md), [UI Guidelines](../UI_GUIDELINES.md), [approved references](references/README.md), [U2 library](U2_MEMORY_LIBRARY_2026-10-23.md), [PLAN](../../PLAN.md).

## Проблема

Исходный экран располагает до текста заметки длинный горизонтальный список типов записи, а между основным содержимым и диктовкой — распознанный текст, настройки псевдонимов и индекса. На небольших экранах текст и голос теряются среди технических опций. При раскрытии клавиатуры нижняя кнопка сохранения должна оставаться доступна и не перекрывать системную навигацию.

## Решение

- Первая область: название страницы, **раздел**, **заголовок**, **основной текст**, **голос**. Без изменения функции `VoiceInput`.
- «Параметры записи» — раскрываемый, управляемый текущим компонентом блок; внутри прежние **Тип записи, Другие имена, Слова поиска, подсказанные моделью слова**. Метаданные сохраняются теми же методами SQLCipher (`setEntityKind`, `setAliases`, `setIndexTerms`); изменение размещения не меняет данные.
- «Текст из файла» — отдельный раскрываемый блок для сохранённых исходников/распознанного текста. Показ под контролем пользователя, редактирование и повторное распознавание сохраняются. Данные не выгружаются и не удаляются при сворачивании.
- «Не сохранено» показывается при реальных изменениях полей; выход по Back с подтверждением. Выход без сохранения должен **не** записывать черновик в память.
- Кнопка **Сохранить запись** остаётся вне прокручиваемой формы и доступна над Android IME; отступы учитывают переключение клавиатуры и нижний системный inset; SDK 57. Цвет и радиусы — существующие Nebula tokens. Тема прочих экранов остаётся пока системной, переход на общую Nebula dark планируется отдельно.
- История, события, связи, защищённые разделы и подтверждение допуска агенту сохраняются как были. Внешние файлы и личные данные не отправляются LLM новым UI-кодом.

## Инварианты

1. Создание → сохранение → возврат. Редактирование текста, типа, псевдонимов, поисковых слов → повторное открытие со всеми значениями.
2. Обратная кнопка Android при несохранённом тексте открывает предупреждение; отмена сохраняет черновик на экране, «Закрыть» не записывает его в БД.
3. Архивация доступна, когда запись не изменена; после сохранения может быть повторена.
4. Диктовка сохраняет текущий ввод, не запускается автоматически при раскрытии метаданных. Отдельная обработка медиа — без изменений.
5. Форма остаётся безопасной при смене профиля/блокировке сессии и отмене распознавания.
6. На 320/360/390/430dp, при тексте ×1.5, Gboard, жестах и трёхкнопочной панели все основные поля и Save доступны; переполнение и горизонтальная прокрутка всего экрана запрещены.

## Проверки

- Jest: доступное раскрытие по кнопке и aria-expanded; скрытые вспомогательные поля; отсутствие стороннего persistent storage у disclosure.
- Playwright: создание, тип Факт в раскрываемом блоке, сохранённые имена после повторного открытия; дисплей 470px с 48px системной панелью; несохранённый черновик не заменяет исходную запись; архив и импорт по-прежнему проходят.
- Maestro: сохранение в нативный SQLCipher, keyboard hide, повторное открытие и архив; полный smoke native release.
- Цветовые референсы REF-ICON-A/B, Skia B+C, анимация чата — НЕ менялись. Никакой подмены artwork.
- **Android на физическом устройстве / шрифты / TalkBack / видео сравнения / safe areas: NOT RUN**, до пользовательского теста не объявлять U2 закрытым.
