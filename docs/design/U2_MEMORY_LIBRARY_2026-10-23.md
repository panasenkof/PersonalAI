# U2 — компактная библиотека памяти (23.10.2026)

**Этапы:** №65/66/87–89. Нормативная очередь — [PLAN.md](../../PLAN.md), [U0–U5](../../Plans/UI_DELIVERY.md).

## Проблема и решение

До первой записи: крупный заголовок, длинное объяснение, три большие кнопки, поиск, разделы, статус, корзина, массовый выбор. При обычной высоте Android первый реальный контент вытеснялся. Длинные названия заметок обрезались одной строкой.

Первый U2-пакет оставляет **поиск и память главными**, не меняя доменную модель:
- Компактный заголовок «Память» + быстрое создание заметки и иконка загрузки файла.
- Поиск со встроенным очистителем, затем горизонтальные разделы и создание нового раздела.
- Фильтры **Записи / Архив / Корзина** видны без вложенной навигации; обновляемый счётчик результатов, компактные ссылки «Копии / Выбрать».
- Массовое **перенести / объединить / удалить / восстановить / окончательно удалить** появляется только после выбора; подтверждения опасных операций и Undo неизменны.
- Карточки используют Nebula spacing/radii, до двух строк для названия и до трёх для текста (сначала body, затем extracted_text), подпись раздела и безопасно отформатированную дату. Полный оригинал заметки не изменяется и остаётся в редакторе.
- Для пустой корзины отдельное понятное состояние. Поиск остаётся серверным SQLCipher с прежним debounce 250ms и пагинацией 50 записей — никаких изменений индексов/секретов/локальной БД.
- Тема экрана по-прежнему следует пользовательской теме ОС; **не** переключаем остальные страницы на dark, пока общий theme adapter не мигрирован. REF-ICON-A/B и Skia не меняются.

## Сценарии/границы

1. «Новая заметка» → редактор → сохранение → возврат: без потери записи.
2. Поиск по заметкам → пустая выдача → очистка → фильтрация по разделам.
3. Архив → выбор записи → возврат в «Записи»; корзина → восстановление; постоянное удаление только после подтверждения.
4. Долгое нажатие на карточку → режим выбора; затем массовое действие и Undo.
5. Списки: 0, 1, 50 и 200 записей; заголовки до 200 символов и Русский 1.5×. Страница 50/100/150 загружается штатным способом.
6. Микрофон, экспорт/импорт, память/шифрование, LLM, фон Home, AppLock и редактор заметок не модифицируются.

## Контроль качества

- Новый Jest: текстовый предпросмотр без изменений оригинала, кириллица, invalid date, открытие/долгое нажатие/выбор, сохранение операций/селекторов.
- Существующий Playwright: создание заметки, сохранение, редактирование, архив, поиск, резервные копии, импорт.
- Android Maestro: вкладка Память → Новая заметка, сохранение → возврат; не исключать из required smoke.
- Требуется зелёный финальный CI SHA: TS/Jest/browser/native SQLCipher APK/Maestro. **Не отмечать PASS без факта**.
- Реальное устройство: ширины 320/360/390/430dp, увеличение текста ×1.5, Gboard, три вида навигационной панели, TalkBack — **NOT RUN** до ручной приёмки.

**U2 не закрыт**: редактор заметок, расширенный UX коллекций, 200-записный тест на устройстве и полноценная тематизация/прозрачные поверхности ждут следующих пакетов. U0/U1 также не закрывать по одному успешному CI.
