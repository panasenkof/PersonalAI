# U3 · Единый путь импорта в память

Дата: 23.10.2026. Предпосылка: #108 (общие Nebula-поверхности); отдельный этап после #107 (редактор заметки).

## Пользовательская проблема

Прежний экран импорта сразу показывал камеру, загрузку URL, локальный файл, настройки провайдера, раздел, тексты и сохранение. На узком экране главный путь был трудно различим. Ввод новой ссылки мог заменить `sourceUrl` заметки, даже когда пользователь фактически сохранил прежний файл без загрузки новой ссылки.

## Поведение U3.1

1. **Источник**: доступны файл, камера и публичный HTTPS URL. После успешного выбора остаются контекст, предпросмотр и кнопка «Изменить источник». Открытие нового выбора не уничтожает текущий черновик и исходник, пока пользователь не подтвердит новый. При Android Share показан полученный материал, без дублирующих кнопок замены.
2. **Предпросмотр и распознавание**: имя файла, изображение и контекстное объяснение политики обработки. Основная кнопка «Извлечь сведения из файла» остаётся доступной. Переключатели моделей перенесены в раскрываемый блок; настройки и ключи не копируются в состояние экрана. Для текста используется локальное извлечение, для внешнего сервиса действуют существующие проверки разрешений.
3. **Проверить и сохранить**: раздел, доступ для агента/закрытый раздел, авторская подпись и отдельный распознанный текст. Сохранение остаётся явным, использует тот же `saveMediaNote` и расписание индексации. Тексты не склеиваются и не записываются в память до подтверждения.
4. URL: отдельно хранится **черновик адреса** и **подтверждённый источник**. Только `importLink` после удачного ответа может подтвердить `sourceUrl`. Ошибка 403/редиректа/сети не заменяет сохранённый файл. Сам импорт не использует cookie или токены.
5. HTML: локально удаляются script/style/nav/header/footer/служебные блоки, по возможности выбирается article/main, декодируются текстовые и числовые entities. Это эвристика для типовой разметки, не гарантия качества для JavaScript-rendered/сложных страниц. Никаких внешних LLM-запросов ради очистки.

## Аудит дублирования

| Действие | Источники / экраны | Решение |
| --- | --- | --- |
| Импорт файла | Вкладка памяти, Home, Android Share | Контекстные входы допустимы; единый MemoryImport и saveMediaNote; не создавать второй обработчик |
| Камера | Home и MemoryImport | Разные входы, общий запрос разрешения и файл в MemoryImport |
| URL | MemoryImport и Android Share | Различать ссылку, сохранённую как текст, и явно загруженный материал |
| Разбор моделью | MemoryImport | Единственная кнопка запуска; список подключений раскрывается по запросу |
| Доступ агента | Экран импорта | Сохранять один активный переключатель для данного типа источника; защищённый раздел имеет приоритет |
| Отправить в чат / сохранить в память | Home и MemoryImport | Не объединять: разные цели; общий транспорт не означает одинаковое поведение |

## Автоматические проверки

- После выбора файла исчезает форма URL, но появляется замена; подготовленный файл не удаляется при редактировании другой ссылки.
- Распознавание сохраняет отдельно текст пользователя и извлечённый текст; настройки модели доступны, но изначально скрыты.
- Share text сохраняется только после явного подтверждения; замена другим источником не предлагается.
- HTML article с навигацией и рекламой очищается; короткая страница без article не теряется; HTTPS/403/редиректы остаются прежними.
- TypeScript/Jest/browser/native CI нужно проверять **на финальном SHA этого PR**. Физические Android: Gboard, камера, Share, фото, аудио, реальные URL и 320–430dp — отдельно, NOT RUN.

## Что не входит в этот PR

Многовложенность №84 и миграция SQLCipher, thumbnails зашифрованных медиа, полноценный проигрыватель/поток мультимодального чата, распознавание по таймкодам №75, платные онлайн-очистители HTML, обход авторизации или ограничений сайтов, правки сферы Nebula B+C и экрана защиты. U3 остаётся частичным до следующих пакетов и приёмки.
