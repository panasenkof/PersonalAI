## Действия владельца проекта (требуется один раз)

1. Скачать `PersAI_Nebula_Approved_References.zip` из разговора и распаковать без пересжатия.
2. В GitHub открыть **PR #72 → ветка `docs/nebula-approved-visual-contract-20261021`**, затем папку `docs/design/references/`.
3. `Add file → Upload files`: загрузить **именно 3 оригинальных бинарных файла** из архива (не скриншот, не пересохранённый preview JPG и не шесть отклонённых минималистичных иконок). Сохранить commit в ветку PR #72, **не** в main.
4. После загрузки проверить размер, показать thumbnails и сравнить SHA-256 по этой таблице (`Get-FileHash -Algorithm SHA256 файл` в PowerShell). При расхождении — не использовать файл, повторить загрузку правильного источника.
5. Убрать эту пометку «не загружены» отдельным коммитом после фактической проверки. Затем вносить графические изменения в APK через отдельные PR.

**Примечание:** оригиналы не содержат бинарного/редактируемого исходника шейдера. Для высококачественной анимации требуется отдельный технический spike; нельзя выдавать вращение картинки за morphing плазменный объект.
