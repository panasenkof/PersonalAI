## Инструкция для разработчика и ИИ-агента

1. Скачать **сам ZIP из текущей ветки**, проверить его SHA-256: `3939d2ccd2b1f814addc4e51802fb5e3875a94f2e456895f8abd82af501b2b2f`.
2. Распаковать в рабочий каталог, использовать `REF-ICON-A.png`, `REF-ORB-B.jfif` и `REF-UI-C.png` как **два раздельных художественных референса и макет**, не подменяя упрощёнными SVG, превью или шестью отклонёнными концептами.
3. Проверить SHA-256 каждого файла по таблице. В PowerShell: `Get-FileHash .\\REF-ICON-A.png -Algorithm SHA256`; аналогично для остальных. Для Python: `hashlib.sha256(path.read_bytes()).hexdigest()`.
4. Производные optimized/mobile assets создавать отдельно, **не модифицировать канонический ZIP**. Оригинал и производные сравнивать side-by-side перед утверждением.
5. **Этот шаг закрывает сохранение оригиналов, но не завершает Figma v0.3, иконку APK, анимированный NebulaCore или Android QA.**
