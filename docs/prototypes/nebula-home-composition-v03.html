Что предстоит согласовать

Теперь проверяем только устройство Home: компактная шапка, просторный чат, закреплённый composer, доступность вложений и голоса.

  • Новый чат: утверждённая сфера REF-ORB-B без баннеров «Чем помочь сегодня?»
  • Диалог: сфера становится небольшим статусным символом, не занимает место сообщений.
  • Ввод: проверка 320/360/390/430 dp и макета клавиатуры.
  • Вложения: выбор типа файла и съёмный чип; это только UX-проба, не обработка файла.
  • Будущие функции: media, automations и инструменты входят в контекстные действия, не размножают вкладки.

После утверждения компоновки — нативный UX-аудит, затем дизайн-система и React Native Home. В настоящий Android переносится уже утверждённая Skia B+C (сфера ×5, контурная нить ×1).
