## 4. Дефект DEF-6 (P2): отказы восстановления без причины

`mobile/src/local-memory/errors.ts` не содержит переводов для кодов восстановления: `restore_requires_empty_memory`, `backup_chat_conflict`, `incompatible_backup_schema`, `incompatible_backup_version`, `invalid_backup_integrity`, `invalid_backup_references`, `backup_manifest_*`, `backup_source_size_mismatch`, `invalid_backup_collection_tree`. Из-за этого `memoryErrorMessage()` отдаёт общий текст, и пользователь не понимает, что именно не так (неверный код? битый файл? память не пуста?).

Именно это и было сутью DEF-1 на первом прогоне — сообщение без причины. Для restore проблема осталась: три разных сценария дали один и тот же текст.

**Рекомендация:** добавить перечисленные коды в `errors.ts` с понятными формулировками (как это уже сделано для `backup_export_*`), отдельным небольшим PR.
