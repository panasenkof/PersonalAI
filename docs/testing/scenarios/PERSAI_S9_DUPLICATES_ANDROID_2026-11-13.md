# PersAI — S9-2: адресная приёмка поиска точных дублей (Android)

**Состояние: NOT_RUN_PHYSICAL / NOT_RUN_LIVE_MODEL.**
Этот сценарий относится к S9-2a/b (read-only). Карточка предложения, объединение и Undo разрабатываются отдельными PR и не считаются реализованными данным тестом. Фиксировать точный SHA/APK и модель. Только синтетические заметки без личных данных.

## Данные
- Создать два-три документа в обычном разделе с одинаковым source_url, разными заголовками.
- Создать две заметки без общего URL, с одинаковым текстом после замены регистра и повторяющихся пробелов; ещё одну — с похожим, но не идентичным текстом.
- Создать копии тех же источников в закрытом разделе, в обычном подразделе закрытого раздела, в архиве, корзине и с индивидуальным sensitive/secret.
- Для одного кандидата добавить вложение и несколько тегов.

## Проверка
1. В чате попросить «Найди дубли по ссылкам». Агент использует только существующий инструмент find_duplicate_candidates с kind=same_url и limit от 1 до 10; получает ID, версии, названия, раздел, количество вложений и тегов. Тексты/URL не входят в результат этого инструмента.
2. Запросить «Найди дубли текста». Должны совпасть заметки с разным регистром и количеством пробелов, но не просто похожие по смыслу. Сравнение идёт на телефоне, через SHA-256 нормализованного текста.
3. Не должны появляться приватные, архивные, удалённые, individually sensitive/secret заметки, даже если они вложены в обычный по виду подраздел секретного родителя.
4. Проверить выдачу групп по 2–5 видимых заметок, максимум 10 групп, отметки totalMatches и moreGroups. При scanTruncated=true помощник не утверждает, что проверена вся память.
5. Выключить AppLock или остановить запрос во время сканирования: результат не должен возвращаться при блокировке; не должно выполняться ни одного действия записи.
6. Повторить обычный запрос в чате после частного чтения «Входящих»: инструменты S9-2 недоступны в ограниченном приватном ходе S9-1; приватный текст не должен быть сохранён в результатах S9-2.

## Отчёт
Приложить SHA/APK, Android, модель, скриншоты двух режимов поиска и отсутствие закрытых записей, логи вызванных инструментов без приватного текста и счётчики групп. Отдельно указать PASS/FAIL/NOT_RUN для каждого шага. Это не тест слияния.
