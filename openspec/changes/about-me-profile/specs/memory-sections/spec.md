## ADDED Requirements

### Requirement: Карточка «Обо мне»
Система SHALL передавать модели в каждом запросе короткую карточку «Обо мне», которую пользователь видит и правит целиком.

#### Scenario: Обращение по имени
- **WHEN** в карточке указано «обращаться: Фёдор»
- **THEN** помощник обращается к пользователю по имени без отдельного поиска в памяти
