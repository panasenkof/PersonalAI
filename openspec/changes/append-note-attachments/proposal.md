# №84: добавить оригиналы к существующей заметке

26.10.2026. Вход: сохранённая активная/архивная заметка → Добавить файлы → системный picker → список → Добавить файлы. Отмена закрывает панель без записи. Файлы можно убрать из списка. Несохранённый текст и диктовку сначала завершить. Новую заметку сначала сохранить.

Существующий текст, классификация, коллекция, источник и расшифровка сохраняются. Новые оригиналы, метаданные, индекс и ревизия фиксируются одной транзакцией с CAS. Ошибка, блокировка или отмена до commit откатывают весь пакет. Повтор старой версии не создаёт дубликаты. До 10 файлов и 80 МБ вместе с существующими; фактические записанные размеры проверяются повторно. Поддерживаются прежние image/audio/video/text и PDF как оригинал, без обещания встроенного PDF-просмотра/распознавания.

Picker-копии удаляются после отмены/сохранения/unmount/истечения сеанса; поздний результат не применяется. Никакой автоматической отправки модели или распознавания. Не меняются SQLCipher-схема, AppLock, транспорт чата и artwork B+C.
