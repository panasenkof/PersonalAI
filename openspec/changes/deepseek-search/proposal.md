# Поиск DeepSeek и чтение страниц

## Why
DeepSeek открыл Search & Fetch API ([документация](https://api-docs.deepseek.com/guides/search/)): поиск по интернету и чтение страницы в Markdown, около $0,75 за 1000 успешных запросов каждого вида, 5 запросов в секунду на аккаунт. Пользователь уже платит DeepSeek за модель и работает из России, где Tavily недоступен. Свежие факты должны находиться тем же счётом и ключом.

## What Changes
- Новый способ интернет-поиска «DeepSeek»: `POST https://api.deepseek.com/v1/tools/search`, `Authorization: Bearer`, тело `{query, ori_question, count: 6, need_content: false}`. Модель получает `summary` и дату каждого результата.
- Ключ: свой ключ поиска или, если подключение — `api.deepseek.com`, ключ подключения.
- Инструмент `read_web_page` (`POST /v1/tools/fetch`) — только при поиске DeepSeek и только для ссылок из результатов этого поиска или из сообщения пользователя: текст найденной страницы не может направить модель на чужой адрес. Не больше 3 страниц на вопрос, текст помечен как данные.
- Ошибки: 401 — ключ, 402 — закончились деньги, 429 — лимит запросов.
- Группы настроек «Модель», «Интернет-поиск», «Умный поиск по памяти», «Голосовой ввод» сворачиваются; в свёрнутом виде видна строка-сводка; что открыто, запоминается.

## Impact
- `direct-agent/web-search.ts`, `settings.ts`, `compatible.ts`, экран подключений, новый `components/Collapsible.tsx`.
- Встроенный поиск DeepSeek внутри чата (как у OpenAI) в документации не описан, поэтому поиск выполняется приложением до запроса к модели, как у Яндекса и Tavily.
