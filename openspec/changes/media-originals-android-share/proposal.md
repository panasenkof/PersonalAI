# Оригиналы и входящие Android

Импорт ранее сохранял только извлечённый текст, поэтому после очистки кэша пользователь
терял доступ к исходнику. Добавляем постоянное зашифрованное вложение, просмотр и
входящие Android SEND/SEND_MULTIPLE. Расшифровка не обязательна для сохранения.

Изменение реализует 60а/61а. Улучшение распознавания, загрузка содержания URL, iOS share
extension и общая администрация заметок остаются следующими задачами.
