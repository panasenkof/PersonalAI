# Решение

Общее memoryText объединяет подпись, распознавание и источник для FTS, чанков,
векторов и контекста агента. При миграции v5 перестраивается индекс; изменённые
векторы рассчитываются локально штатным фоновым обработчиком.
SQLCipher хранит оригиналы и отдельные поля текста. Схема v5 снимает уникальность
entity_id у вложений, сохраняя части файлов и связи транзакционно.
Групповые действия используют версии записей и журнал ревизий; отмена проверяет
всех участников до записи. Максимальная чувствительность сохраняется при объединении.
Входящий материал открывается как черновик после разблокировки; сеть запускается
только по действию пользователя. Камера и ссылки используют очищаемый кеш.
Векторизация бинарных файлов не заявляется: сначала нужен OCR/транскрипт/описание.
