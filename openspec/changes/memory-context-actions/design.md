# Контракт поведения

- SHALL: короткое нажатие открывает заметку; ⋮ открывает её меню без изменения массового выбора. «Выбрать несколько» выделяет эту запись и включает режим.
- WHEN удерживается запись THEN выделяется она, обычная закреплённая шапка заменяется панелью «Отмена / Выбрано: N / Действия».
- WHEN снята последняя галочка или нажата Отмена/Android Back THEN выбор завершается. При явном входе «Выбрать записи» возможен ноль выбранных; действия отключены, выход доступен.
- SHALL: открытый Modal обрабатывает Back первым; закрытие меню сохраняет массовый выбор. Во время необратимой операции повторное выполнение блокируется.
- SHALL: поиск/его очистка, переходы коллекций/ко всем записям и смена раскладки не меняют контекст при выборе; прокрутка доступна. «Выбрать все» отсутствует.
- SHALL: для обычной заметки есть редактор, перенос, архив, корзина; для нескольких — перенос/архив/корзина, объединение с предпросмотром только для двух и более активных. Архив предлагает возврат; корзина — восстановление/удаление навсегда.
- WHEN выбрана корзина/удаление навсегда THEN тот же лист переключается в подтверждение с числом записей; операции не исполняются до подтверждения. Cancel/Back возвращают действия без потери выделения. В фоне общий BottomSheet скрывается существующим privacy-контроллером.
- WHEN операция успешна THEN выбор завершён; WHEN ошибка THEN выбранные записи и повтор доступны. Архив и возврат выполняются существующим транзакционным механизмом с CAS, ревизиями, индексом и undo без миграции.
- SHALL: отмена называет тип операции; меню библиотеки не повторяет добавление и коллекции. Действия с коллекциями не выполняются над её заметками автоматически.
- SHALL: checkbox и ⋮ имеют постоянное место; размер карточки не меняется от выбора. Обновление той же выборки не размонтирует весь список; новый фильтр очищает устаревшие результаты.
- SHALL: невиденные обложки не расшифровываются. Виденная обложка сохраняется только у смонтированной карточки в ограниченном render window FlatList; blur/background/lock/unmount очищают открытые файлы. Межэкранного и постоянного plaintext-кэша нет.
- SHALL: коллекции получают стабильные нейтральные значки, оригинальные фото остаются на карточках заметок.

Ограничения: после ухода со страницы/размонтирования миниатюра создаётся снова для соблюдения очистки. Android Back, TalkBack, увеличенные системные шрифты и native insets требуют устройства. Браузерная имитация не равна Android-приёмке.
