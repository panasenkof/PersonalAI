# Память: меню заметки и предсказуемый выбор

25.10.2026 — утверждённый мини-план владельца. Нажатие открывает запись, ⋮ показывает её действия, удержание включает массовый выбор. Выбрать все не требуется. Завершить одним PR выход по Отмене/Back/последней галочке, архивирование с отменой, компактное меню и стабильные карточки.

## Сверка с соседним аудитом

База содержит #121 и новый mobile-ui-ux из #122. Проверен [PR #123](https://github.com/panasenkof/PersonalAI/pull/123), документ `UX_REVIEW_FROM_DEVICE_2026-10-25.md` на SHA `8c94668391fd06ed45bec71ec58acb3a8e52f25a`.

- P1-A: разделены контекст одной записи и массовый выбор; панель заменяет шапку. Предложение аудита «удержание → меню» НЕ применяется: более поздний утверждённый мини-план задаёт «удержание → выбор».
- P1-B: устранить наложение Alert и BottomSheet. Здесь выбран более простой один Modal: подтверждение заменяет содержимое панели действий; отмена возвращает действия с теми же записями. Нет задержек, второго native окна или изменений AppLock.
- P1-C: из меню памяти удалены дубли добавления/коллекций; сохранены короткие фильтры и контекстная ссылка на существующие резервные копии. Новый экран навигации не нужен.
- P2-A: коллекции используют стабильные нейтральные значки вместо случайного фото записи; изображения самих заметок сохраняются. Дефолт списка/сетки не меняется без отдельной проверки владельца.
- P2-B/C: чат, composer, импорт и настройки в этот пакет не входят. Их Android-приёмка остаётся U5.

## Основание паттерна

Benchmark: повторное исследование N/A — реализуется уже утверждённый точный паттерн. Использованы результаты сравнения 25.10.2026 и #123: [Google Keep](https://support.google.com/keep/answer/6262765?co=GENIE.Platform%3DAndroid&hl=en), [Android contextual actions](https://developer.android.com/develop/ui/views/components/menus), [Apple Notes](https://support.apple.com/en-gb/118442). Это документация, а не утверждение о тестировании приложений. Adopt: понятный выбор и Back. Adapt: компактные связанные действия в Android BottomSheet. Reject: iOS-only жесты и смешение одиночного меню с bulk state.

Область: список/карточки памяти, временные превью, существующие атомарные note-actions. Сфера B+C, identity, SQLCipher-схема, LLM, микрофон, настройки и required minimal Maestro не изменяются. Снимки в PR только синтетические.
