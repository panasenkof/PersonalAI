## Короткая проверка владельца

1. Открыть ⋮ одной заметки; закрыть — галочек нет. Удержать её — выбор одной.
2. Выбрать вторую; отменить меню, затем Android Back — список без выделения. Повторить со снятием последней галочки.
3. Архивировать тестовые заметки, вернуть и отменить операцию. Проверить текст/оригиналы.
4. В корзину → отменить подтверждение: то же выделение. Подтвердить → восстановить из корзины. Необратимое удаление — только на ненужных тестовых данных.
5. При скролле/меню уже виденные смонтированные обложки не перезагружаются. После ухода со страницы новое декодирование допустимо ради очистки открытых файлов.

P2 за пределами пакета: изменить дефолт сетка/список — только после сравнения; чат/composer/импорт/настройки из #123 остаются отдельной приёмкой U5. Переименование/удаление коллекций и новые файлы в заметках не добавлены.
