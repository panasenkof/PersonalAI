# Индексные слова и поиск через связи

## Why
Поиск по словам не находит «сестру» по слову «родственница» и не понимает, что «что любит сестра» — это про Аню. У DeepSeek нет эмбеддингов, но его чат может один раз при сохранении записи подобрать к ней слова, по которым её будут искать.

## What Changes
- При сохранении записи из обычного раздела выбранная модель (по умолчанию — активное подключение, например DeepSeek) возвращает JSON: синонимы, связанные понятия, формы имён, нормализованные даты, люди и проекты, к которым относится запись.
- Индексные слова пишутся в `memory_index_terms` и в колонку `terms` FTS; люди — в имена/прозвища и связи.
- Поиск: после совпадения с человеком подтягиваются его факты.
- Записи «Документов» не отправляются модели; для них индексные слова не строятся.
- Старые записи обогащаются в фоне, пачками, только при разблокированном приложении; повтор после сбоя.

## Impact
- Один короткий запрос к модели на каждую новую или изменённую запись.
- `mobile/src/direct-agent/memory.ts`, новый модуль обогащения, экран записи (показ и правка индексных слов).
