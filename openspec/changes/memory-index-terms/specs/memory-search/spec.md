## ADDED Requirements

### Requirement: Поиск по индексным словам
Система SHALL находить запись по индексным словам, которые модель подобрала при сохранении, и по именам и прозвищам людей.

#### Scenario: Синоним
- **WHEN** запись «Сестра Аня любит кофе» сохранена с индексными словами «родственница, семья, Анна»
- **THEN** вопрос «что любит моя родственница?» находит эту запись

### Requirement: Поиск через связи
Система SHALL при совпадении с человеком или проектом добавлять к результатам связанные с ним факты.

#### Scenario: Вопрос про человека
- **WHEN** вопрос «что подарить Ане?» совпал с записью-человеком «Аня»
- **THEN** в результаты попадают её предпочтения и важные даты
