# Переформулировка вопроса и выбор лучших записей

## Why
Если способы поиска ничего не дали, вопрос мог быть сформулирован непривычно. Перед тем как сообщить «в памяти ничего не нашлось» и идти в интернет, модель может переформулировать вопрос и указать фильтры.

## What Changes
- Если поиск по словам, индексным словам, связям и векторам пуст, модель возвращает 3–5 вариантов запроса и фильтры (раздел, человек, период), и поиск повторяется.
- Результаты всех способов объединяются (RRF) с поправкой на свежесть и раздел; при спорных совпадениях модель выбирает 5 лучших из 20.
- Под ответом видно, какие записи использованы и каким способом найдены; запись открывается и правится.
- Данные из памяти и интернета передаются модели в сообщении пользователя как данные, а не в системной инструкции.

## Impact
- Один дополнительный короткий запрос к модели только для вопросов, на которые память сразу ничего не дала.
