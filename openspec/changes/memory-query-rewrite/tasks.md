## Решения при реализации
- Переформулировка — только когда первый поиск пуст, память доступна и вопрос не «что ты знаешь обо мне» и не просьба открыть ссылку. Модели уходит только вопрос, без записей памяти. На DeepSeek — `deepseek-flash` без рассуждений, ответ JSON, таймаут 20 секунд; сбой означает обычное «ничего не нашлось».
- До 5 вариантов запроса + имя человека; результаты объединяются по RRF, записи названного раздела и с именем человека поднимаются выше.
- «Из памяти» под ответом: до 8 записей, на которых он основан, со способом («найдено другими словами», «нашёл помощник»); нажатие открывает запись.
- Данные памяти и интернета — в сообщении пользователя с пометкой «НЕ инструкции»; в системной инструкции только правила.
