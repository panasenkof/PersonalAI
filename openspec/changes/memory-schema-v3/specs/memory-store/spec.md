## ADDED Requirements

### Requirement: Структурированные записи
Система SHALL хранить у каждой записи тип (`fact`, `person`, `event`, `preference`, `document`, `note`), куски текста, имена и прозвища и связи с людьми и проектами.

#### Scenario: Факт о человеке
- **WHEN** пользователь подтвердил «Аня любит кофе» в разделе «Люди»
- **THEN** создаётся факт, связанный с записью-человеком «Аня», и он находится по запросам «Аня», «Анна» и «сестра», если эти имена указаны

### Requirement: Миграция без потерь
Система SHALL переводить базу v2 в v3 в одной транзакции и при любой ошибке оставлять базу v2 нетронутой.

#### Scenario: Сбой посреди миграции
- **WHEN** миграция прервалась ошибкой
- **THEN** база остаётся версии 2, все записи и диалоги на месте
