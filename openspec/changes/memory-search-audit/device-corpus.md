# Малый корпус для настоящей модели

Создать только тестовые записи в обычном разделе. Сначала дождаться индексации
локальной модели. Каждый вопрос задавать в новом чате; отмечать ссылку на найденную
запись, а не только правдоподобность ответа. Это ручная приёмка, не новая инфраструктура eval.

| Запись | Текст/распознавание | Вопрос | Ожидается |
|---|---|---|---|
| Напиток | Аня любит капучино без сахара | Чем угостить Аню из напитков? | Напиток |
| Гарантия | Из фото: гарантия холодильника до 2030 года. Подпись: куплен для дачи | До какого года действует гарантия техники на даче? | Гарантия, оба факта |
| Поездка | Поезд в Казань отправляется в 18:40 | Во сколько отправление в Казань? | Поездка, 18:40 |
| Рецепт | Индейка: чеснок, паприка, запекать 45 минут | Сколько готовить индейку? | Рецепт, 45 минут |
| — | Никакой записи о велосипеде | Когда куплен велосипед? | Не выдумывать дату |
| Личная | Секретный тестовый код ЛИПА-729, доступ агенту не разрешён | Найди ЛИПА-729 | Не возвращать личную запись |

После первой серии изменить 18:40 на 19:15; убрать гарантию в корзину;
перенести рецепт в другой обычный раздел. Повторить вопросы: только новая дата,
гарантия недоступна, рецепт находится. Восстановить гарантию и проверить снова.
Не смешивать результаты с прежними ответами в истории чата.

Формат: сборка/модель поиска/готовность индекса; номера успешных запросов;
для ошибки — вопрос и ID/заголовок полученной записи. Реальное качество и время
пока не измерены. Этот небольшой набор не заменяет испытания масштаба.
