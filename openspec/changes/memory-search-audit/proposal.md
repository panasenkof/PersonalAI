# Актуальность поиска и организация памяти (66, 56)

После медиаимпорта и групповых операций сначала обеспечиваем соответствие
поискового индекса текущим данным. Не сокращаем контекст и не меняем лимиты LLM.

Обнаружено: поиск использовал старый вектор после изменения заголовка, хотя
очередь уже считала его устаревшим. Завершившаяся поздно индексация могла записать
результат для прежнего содержимого под тем же ID фрагмента.

Исправление: проверять хеш заголовка и текста при записи и чтении вектора.
Удалённые/неактивные записи и некорректные численные векторы не принимать.
