# №72.2 / M4-UX (U-M5/U-M6) — первая реальная карточка проверки временного факта

## Текущий результат (PR, required CI pending)
- Отдельный Stack screen `MemoryTemporalReviewScreen` без новой вкладки; вход только из явно выбранной standard-секции «Память», доступ после проверки актуального source scope в `temporalReviewInbox`.
- Показывает прежнее/новое значения, обе цитаты источников, статус pending/deferred, предупреждение об отсутствии автоматического изменения фактов. Не показывает количество закрытых/скрытых предложений и не выполняет полный перебор.
- Варианты: **«Подтвердить изменение»** (только `possible_change`), **«Оставить оба»**, **«Позже»**, **«Не предлагать»**. У `possible_reconfirmation` нет ложного сценария «завершить предыдущее».
- При явном подтверждении: выбрать корректную дату `YYYY-MM-DD` с проверкой реального дня либо «Дата неизвестна». Не подставлять текущий день. Проверка CAS/revisions, SQLCipher transaction + immutable decision journal остаются в #169.
- После решения — **«Отменить последнее решение»** с точными версиями и оригинальным decision ID. Отдельный долговременный экран всей истории отмен ещё не сделан.
- При смене профиля/закрытии AppLock или повторной проверке терять устаревшие local React items, а не продолжать показ закрытых цитат из UI-кэша. Дата не конвертируется в UTC timestamp, хранится как typed calendar day.
- Выдерживать 320dp+, перенос длинных меток, 44–48dp touch, доступность, скролл на длинном списке, error/reload и pagination. Nebula-сфера/чат не меняются.

## Негативные C1
Показывается только одна активная collection стандартного доступа. Действия не вызываются до onPress; ошибка версий не перезаписывает данные. Отложенное предложение остаётся доступным; реальные исходные цитаты приходят только из репозитория; выбор `2025-02-30` не может подтвердить изменение; `2024-02-29` корректен; неизвестная дата не превращается в «сегодня»; Undo сохраняет журнал; блокировка приложения мгновенно очищает чувствительный текст; выбор категории с unclassified не открывает review entry.

## НЕ ГОТОВО
- Автоматическое выделение типизированных claims из произвольной заметки/чата и cross-section scope; пользовательский экран показывает только уже сформированные предложения, без ложного обещания полной памяти.
- Связи людей и участие в беседе с доказательствами/миграцией/решениями; U-M2 объект, U-M3 хронология, U-M4 открытие оригинала по page/time, U-M7 privacy manager, U-M9 unified agent search, U-M10 групповая ревизия. UX U-M5/U-M6 — только первая временная вертикаль.
- Журнал всех старых отмен на UI, изменяемая точность месяц/год, исправление ошибочной identity, batch accept, физическая приёмка Android. Эти функции остаются в PLAN §2 M1–M4, не подменяются зелёным CI.
