## ADDED Requirements

### Requirement: Смысловой поиск на телефоне
Система SHALL, если модель векторов скачана, находить записи по смыслу без общих слов с вопросом, вычисляя векторы только на телефоне.

#### Scenario: Нет общих слов
- **WHEN** в памяти «Аня любит кофе», а вопрос «чем угостить Аню?»
- **THEN** запись найдена смысловым поиском

#### Scenario: Модель не скачана или Android ниже 13
- **WHEN** модели векторов нет
- **THEN** поиск работает остальными способами, без ошибок
