## Решения при реализации
- Модель: `models.textEmbeddings.PARAPHRASE_MULTILINGUAL_MINILM_L12_V2` из `react-native-executorch` 0.10.5, `createTextEmbedder` → `embed(text)` возвращает нормированный вектор из 384 чисел. Скачивание — по кнопке, с прогрессом и отменой; совет «лучше по Wi-Fi», без запрета мобильной сети.
- Вектор считается для «названия + куска»; актуальность — по хешу этого текста, так что правка названия тоже пересчитывает. Смена текста пересоздаёт кусок, его вектор удаляется каскадом.
- Векторы считаются для всех разделов, включая «Документы»: они не покидают телефон. Что уходит модели, по-прежнему решает фильтр разделов при поиске.
- Поиск: косинусная близость по всем векторам профиля, лучший кусок на запись, порог 0,45; объединение со словами по RRF (k = 60). Без модели или без близких кусков поиск по словам не меняется. Вектор вопроса ждётся не дольше 3 секунд.
- Фон: после скачивания, после сохранения записи, через 10 секунд после запуска; по 16 кусков; останавливается при блокировке и при удалении модели. В карточке видно «Векторы: N из M» и время на кусок.
- В CI модель не запускается (нативная): поиск по смыслу проверяется тестом с игрушечными векторами; точность на проверочном наборе и порог 0,45 — на телефоне (3.1), время индексации — там же (3.2).
