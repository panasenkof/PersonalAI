# Требования Skia B+C

### SPEED-01
WHEN Lab открыта, THEN sphere ×5 и filament ×1; независимый `uLineTime`, idle без нити.

### SPEED-02
WHEN включено сравнение, THEN сфера ×1, нить остаётся ×1, яркость и энергия не увеличиваются; отключение возвращает сферу ×5.

### SPEED-03
WHEN состояние thinking, THEN амплитуда контура +~20%, выразительнее пульс неоновой нити без повышения её скорости/частоты.

### SPEED-04
WHEN нить отображается на насыщенной B-плазме, THEN различимый цветной контур имеет тонкую контрастную подложку и сохраняет два halo, остаётся привязанным к деформированной границе.

### SPEED-05
WHEN система требует остановить движение или режим offline/error, THEN обе временные координаты нулевые и остаётся статичная статусная нить.

### SPEED-06
WHEN PR проверяется, THEN компиляция SkSL, TypeScript/Jest/CI и Android native build должны пройти, а визуальное принятие на устройстве остаётся отдельным.
