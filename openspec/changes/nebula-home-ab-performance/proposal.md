# A/B comparison gate for native Nebula Home

Утверждённая сложная Skia B+C уже интегрирована в Home; после PR #91 исправлено поведение при Gboard. Следующий контроль качества — возможность **сравнить один и тот же визуал при live/static на реальном Android**, чтобы измерить расход ресурсов без угадывания.
