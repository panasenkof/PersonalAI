# Nebula Home: исправить обрезание сферы при Gboard

Вход: пользовательский скриншот Android (22.10.2026): открыта русская Gboard, в composer «При», большая сфера заходит под верхнюю панель composer и визуально обрезана.

Спецификация: [docs/design/NEBULA_HOME_KEYBOARD_LAYOUT.md](../../../docs/design/NEBULA_HOME_KEYBOARD_LAYOUT.md). Это исправление HOME-04, **не redesign экрана «Защищено»** и не смена художественного B+C.

Цель: динамическая композиция по реальной высоте списка; при клавиатуре компактная сфера ≤96dp, при недостатке места скрыть; запрет auto-scroll пустого чата; обеспечить отправку, клавиатуру и историю.
