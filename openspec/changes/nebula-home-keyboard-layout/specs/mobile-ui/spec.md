# IME / Nebula Home

## HOME-IME-01: Responsive state orb
WHEN пользователь открыл клавиатуру Android на пустом чате THEN сфера уменьшена до ≤96dp и полностью видна в измеренном viewport либо скрыта, если не хватает места. WHEN клавиатура закрыта THEN возвращается большая сфера до 320dp по фактической высоте списка и ширине.

## HOME-IME-02: Чат и прокрутка
WHEN нет rows/streamText THEN `onContentSizeChange` **не** запускает `scrollToEnd`. WHEN реальные сообщения/streamText есть THEN чат может продолжать скроллить к ответу, а статусная сфера ≤80dp или скрыта при маленькой высоте.

## HOME-IME-03: Поведение без регрессий
WHEN пользователь печатает/очищает/отправляет/останавливает запрос, открывает File/Camera, переключает вкладку и возвращается THEN composer и данные работают прежде; голосовая/LLM-фаза, Skia B+C и accessibility не нарушаются.

## HOME-IME-04: Проверка
WHEN CI проходит THEN screenshot с Gboard всё равно проверяется на устройстве отдельно. Не утверждать Android IME пиксельную приёмку по результату веб-эмулятора.
