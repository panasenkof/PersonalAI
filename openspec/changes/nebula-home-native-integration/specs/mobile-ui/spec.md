# Nebula Home B+C

## HN-01: Живой графический объект

WHEN пользователь открывает **Home на Android**, а в чате нет сообщений, THEN вместо круглого неподвижного PNG Android отображает нативную многоуровневую Skia B+C на согласованном тёмном космическом фоне, контурная нить отсутствует в idle. Лаборатория сохраняет отдельные режимы. Нет диска и квадратных границ.

## HN-02: Реальные состояния

WHEN фактический движок речи сообщает listening/finishing, THEN сфера показывает listening/transcribing. WHEN отправленный запрос занят и не выдал текст, THEN thinking. WHEN streamText реально поступил, THEN responding. WHEN нет события, THEN idle без фиктивных статусов.

## HN-03: Сохранение чата

WHEN пользователь начинает писать, отправляет сообщение, переключает вкладку и возвращается, THEN история, отправка, остановка, черновик, память и composer остаются на месте и работают. Большая сфера не мешает потоку ответов и клавиатуре.

## HN-04: Доступность и безопасность

WHEN Home не в фокусе, THEN native Skia clock размонтирован. WHEN Android Reduce Motion/background, THEN анимация остановлена, качественный static fallback доступен. Остальные вкладки сохраняют существующую тему, биометрию и структуру данных.

## HN-05: Проверка

WHEN CI runs, THEN unit/SkSL/typecheck/browser/Android build успешны. Device визуальная и GPU/FPS приёмка остаётся открытой до фактического теста APK.
