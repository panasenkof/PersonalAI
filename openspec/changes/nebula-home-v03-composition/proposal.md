# Nebula v0.3 — компоновка рабочего Home после утверждения сферы

Владелец 22.10.2026 согласовал окончательный художественный дизайн сферы B+C, больше не экспериментировать с её формой. Главная страница пока использует старую шапку, крупные приветствия и прежний FloatingBrand, а новая дизайн-система не интегрирована.

**Цель следующего UX-этапа:** точный интерактивный/редактируемый макет Home, затем UX-аудит настоящего APK, и только после этого UI-миграция небольшими PR. [Нормативная очередь](../../../docs/design/NEBULA_PRODUCTION_ROLLOUT.md).

**Не входит:** новый шейдер/иконка, изменения SQLCipher, LLM, микрофона, новые рабочие multimodal capabilities и выпуск false-functional UI-заглушек.
