# Home v0.3 — визуальный и функциональный контракт

### H-01 — Основная площадь чата
WHEN открыт Home с сообщениями THEN история занимает основную часть экрана, шапка компактна, снизу доступен composer. WHEN чат пуст THEN можно показывать утверждённую сферу без «Чем помочь сегодня?» и блоков случайных советов.

### H-02 — Управление вводом
WHEN пользователь фокусируется на текстовом поле THEN открывается **только выбранная им системная клавиатура Android**, а не кастомная клавиатура PersAI. WHEN открыта Android IME, изменён размер шрифта или 3-button navbar THEN поле ввода, микрофон, отправка и кнопка вложений остаются доступны через native WindowInsets/adjustResize, без наложения, скачков или дублирования. Длинный prompt скроллится внутри composer.

### H-03 — Реальные состояния ассистента
WHEN LLM или микрофон переходит между idle/listening/transcribing/thinking/responding/offline/error THEN компактная фирменная сфера использует **реальное** состояние операции, а не симуляцию; при background, Reduce Motion и экономии показывается правильный статичный вариант.

### H-04 — Художественная неизменность
WHEN NebulaCore появляется на рабочем экране THEN форма/материал/скорости B+C, независимая нить и thinking совпадают с утверждённым эталоном; нельзя подменять Skia упрощённым кругом.

### H-05 — Приватность и сохранность
WHEN пользователь переключает вкладку, добавляет вложение или открывает память THEN существующие диалоги, ключи/настройки, зашифрованные локальные записи и фоновые ответы не теряются. Внешний вид кнопки не должен выдавать отсутствующие multimodal capabilities за готовую функцию.

### H-06 — Device QA
WHEN готовится UI PR THEN требуются реальные Android скриншоты, безопасные отступы, сценарии клавиатуры, 320/360/390/430 dp, шрифты 1.3×/1.5×, TalkBack, FPS/battery для постоянно работающего Skia и регрессионные тесты с результатами PASS/FAIL/NOT RUN.
