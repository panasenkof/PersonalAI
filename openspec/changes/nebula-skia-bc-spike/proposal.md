# Nebula hybrid B+C Skia — R&D proposal

## Решение
Владелец утвердил **детализацию, объём и космическую глубину B плюс движение C**. В [визуальном контракте](../../../docs/design/NEBULA_HYBRID_BC_DECISION.md) приоритет художественной детализации выше упрощённой скорости.

## Изменения
- Поддерживаемые Expo 57 пакеты Skia 2.6.2 / Reanimated 4.5.1, Worklets 0.10.1 (без апгрейда RN и Expo).
- Исходный REF-ORB-B JFIF берётся из проверенного ZIP, генерируется однозначный производный PNG, исходник не изменяется.
- Изолированный `NebulaSkiaExperiment` показывает procedural B+C с native shader, статусами и fallback.
- `NebulaSkiaLabScreen` — ручной тестовый экран **без подключения к текущему Home**.
- Android release build и визуальное сравнение с видео B прежде внедрения.

## Вне объёма
- Продакшн интерфейс, изменение диалогов и памяти, LLM, мультимодальная отправка, системные разрешения и реальная включённая анимация.
- Слияние незавершённой video-ветки в данный PR.
