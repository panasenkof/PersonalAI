# Nebula B+C native R&D — acceptance scenarios

## Требование NB-01: Утверждённая детализация B и органическое движение C
Рендер SHALL основывать форму и детали на оригинальном REF-ORB-B, SHALL добавлять независимые движущиеся мембраны и локальную рефракцию. Один radial-gradient или scale PNG SHALL NOT считаться выполнением.

### Сценарий: Skia Canvas
**WHEN** открыта изолированная SkiaLab на устройстве, Reduce Motion выключен, `idle`  
**THEN** виден нативный Skia Canvas с исходной текстурой и органическими многослойными эффектами  
**AND** оригинальная форма/свет сохраняются, нет квадратных артефактов.

## Требование NB-02: Безопасное отключение анимаций
**WHEN** Android Reduce Motion включён, либо приложение свернуто, либо power constrained  
**THEN** native animation останавливается и показывается качественный статический REF-ORB-B  
**AND** отображение текста статуса сохраняется.

## Требование NB-03: Визуальное решение владельца
**WHEN** нативный эксперимент и видео-B доступны как одинаковые по масштабу записи  
**THEN** владелец может сравнить форму, насыщенность, динамику, FPS и нагрузку  
**AND** система не выбирает финальный рендер автоматически.

## Требование NB-04: Не ломать рабочее приложение
**WHEN** PR Skia R&D объединён с main  
**THEN** текущие Home, Memory, Settings, LLM, аудио и защищённые данные работают без изменения UI  
**AND** SkiaLab не является обязательной новой вкладкой.
