# Инструменты PersAI: исследование и очередь подключения

Проверка официальных документов: 19.10.2026. Это кабинетное исследование; реальное
подключение аккаунтов, региональная доступность и совместимость мобильного клиента
ещё не проверены. Тарифы меняются: перед реализацией повторно проверять источник.

## Архитектура подключения

LLM видит небольшое релевантное подмножество общего каталога, а приложение исполняет
вызовы и проверяет результат. Секреты не входят в контекст модели. HTTP/MCP — способы
подключения, не новые полномочия. Нужны одинаковые правила для всех трёх LLM-протоколов.

| Путь | Когда использовать | Ограничение |
| --- | --- | --- |
| Нативный API / системное действие | Календарь, файлы, камера, уведомления, Share Target | Разрешения и жизненный цикл ОС; открытие формы не доказывает сохранение |
| HTTP REST | Конкретный официальный сервис с устойчивым API | OAuth, квоты, проверка результата; не универсальный fetch любых URL от LLM |
| WebDAV / CalDAV / IMAP | Файлы, календари и почта у нескольких провайдеров | Нужны адаптеры и проверка различий; это не HTTP JSON и не автоматически MCP |
| Удалённый MCP | Готовый проверенный сервер с полезными инструментами | Авторизация, версия протокола, сервер может быть платным или preview |
| Workflow/webhook пользователя | Несколько связанных сервисов, например n8n | Опциональный внешний исполнитель; подписанные запросы, схема входов и статус задания |
| Deep link / «Открыть в» / экспорт ICS | Завершение действия в другом приложении | Часто нет надёжного подтверждения результата; честный статус передачи |

Паспорт инструмента: ID и версия, назначение, входная схема, результат, права,
эффект (чтение/изменение/отправка), стоимость, лимиты, таймаут, отмена, повтор,
идемпотентность, проверка результата, тестовый исполнитель и поддержанные аккаунты.
При обновлении описания/прав MCP показывать изменение и не расширять доступ молча.
Проверять OAuth redirect/state/PKCE, отзыв и обновление токена; не встраивать секрет
конфиденциального OAuth-клиента в APK. Выбор схемы зависит от провайдера.
Не запускать произвольные stdio-серверы/скрипты из каталога MCP на телефоне.

## Кандидаты: возможности, экономика и порядок

«Без отдельной платы за API» не означает бесплатную LLM, хранилище, подписку или
хостинг. Неизвестную стоимость помечать неизвестной. Бесплатность личного использования
не переносить автоматически на публичный коммерческий выпуск.

| Кандидат | Полезные действия | Подключение и доступность по документам | Экономика | Очередь |
| --- | --- | --- | --- | --- |
| Файлы и календарь телефона | Сохранить/открыть файл, добавить событие, локальное напоминание | Нативные API/системные формы [R4] | Нет платы за внешний API; память устройства | Первая |
| Яндекс Диск | Выгрузить файл, список папок, backup/restore | REST или WebDAV, OAuth [R5] | Бесплатный объём 5 ГБ по справке; дополнительное место платное, тариф/API-условия перепроверить [R6] | Первый облачный кандидат |
| Nextcloud / свой NAS | Файлы и резервные копии, календарь, контакты | WebDAV; CalDAV/CardDAV исследовать для выбранного сервера [R7] | Самостоятельное размещение требует диска/сервера и обслуживания; не «бесплатное облако» | Альтернатива Диску |
| Google Drive | Файлы и backup | REST; официальный remote MCP в Developer Preview [R8, R10] | Стандартное API без доплаты в пределах условий; место и будущие сверхквотные расходы отдельно | Вторая волна |
| Google Calendar | События, занятость, поиск времени | REST; remote MCP в Developer Preview [R11] | Стандартное использование без доплаты; квоты и переход к оплате превышений проверять | После локального календаря |
| Gmail | Прочитать сегодняшние письма, найти вложение, подготовить черновик | REST; MCP preview; OAuth restricted scopes [R9, R12] | Квоты API и возможная стоимость выпуска/верификации; LLM отдельно | Read-only пилот |
| Outlook / OneDrive | Почта, события, файлы | Microsoft Graph; вид аккаунта и права проверяются прототипом [R13] | Стандартные API входят в соответствующую лицензию; отдельные metered API платные | По спросу |
| Яндекс Почта / иной IMAP | Список/чтение писем, вложения | IMAP с разрешённым провайдером способом входа [R14] | Тариф ящика, LLM и возможный мост отдельно; универсальной бесплатности не обещаем | Альтернатива Gmail |
| S3-совместимое хранилище | Большие шифрованные архивы, версии и retention | S3 API конкретного провайдера [R15] | Платные объём, запросы, извлечение и трафик; бесплатные предложения не считать постоянными | После простых облаков |
| Home Assistant | Состояние дома, управление выбранными устройствами | Официальная MCP-интеграция и Assist API [R16] | Собственная установка/оборудование; облачные опции отдельно | Поздний opt-in |
| n8n пользователя | Связать сервисы и выполнить расписание на его сервере | Webhook или проверенный MCP-интерфейс [R17] | Community self-hosted по SUL; сервер и сторонние API стоят отдельно; Cloud платный | Опционально |
| Open-Meteo | Погода для поездки и ежедневной сводки | HTTP [R18] | Бесплатный API для некоммерческого использования с лимитами; коммерческий доступ платный | Небольшой пилот |
| RSS/Atom и страницы | Новости по выбранным темам, контроль обновлений | HTTP, условия каждого издателя | Нет универсальной платы за протокол; доступ к контенту может быть платным | После заданий |
| Локальные вычисления | Даты, единицы, суммы, списки, экспорт текста/ICS | Детерминированные функции приложения | Без внешнего API, LLM для самого вычисления не нужна | Ранняя волна |

Google Workspace MCP действительно представлен в официальных документах, но требует
участия в preview; не делать его единственным путём для обычного пользователя.
Нативные/REST-адаптеры первой волны предпочтительны для контролируемого малого набора.
Для MCP провести проверку актуальной спецификации и согласования версии [R19],
схем, pagination, cancellation, недоступного сервера и изменения списка tools.

## Что ещё исследовать, прежде чем включать в обязательную очередь

- Задачи и списки покупок: сначала локальные, затем Todoist/Microsoft To Do/CalDAV;
  проверить текущий API, бесплатные функции и лицензию. Пока экономику не подтверждали.
- Карты/маршруты/транспорт: сначала открыть маршрут в выбранном приложении; затем
  сравнить провайдеров по доступности региона, квотам и платным маршрутам.
- Контакты и подготовка к встречам: подбор связанных заметок и писем, без автоматической
  рассылки. Разрешение контактов отдельно от чтения календаря.
- Чеки, покупки, гарантии: фото → подтверждённые поля → срок/напоминание; без платежей.
- Домашние документы и обслуживание автомобиля: история, сроки, инструкции; приватные
  разделы сохраняют существующий запрет внешней обработки.
- Здоровье/активность: только отдельный исследовательский этап прав и чувствительных
  данных, без автоматических диагнозов и изменений лечения.
- Поиск потерянного материала: «где было видео про…» → поиск по транскриптам и источникам.
- Перевод речи/надписей и учебные карточки из собственных материалов: оценить локальные
  движки, источники, качество и режим offline.
- PDF/скан/документ/таблица: после устойчивых медиа расширить извлечение текста,
  структуру таблиц и экспорт; не считать PDF обычным изображением без страниц.
- Мессенджеры: отдельное исследование официальных API и границ личного аккаунта/бота;
  наличие бота не даёт доступ ко всем личным перепискам.

Для каждого кандидата сделать карточку: пользовательский сценарий, официальная
документация, статус стабильности, авторизация, регион/тип аккаунта, бесплатный уровень,
полная стоимость типичного месяца, данные за пределами телефона, прототип, тесты,
поддержка и альтернативный путь. Выбирать по пользе и стоимости сопровождения, а не
по числу инструментов в каталоге. Статусы: исследован → прототип → приёмка → доступен.

## Практические референсы и идеи из фантастики

Это наши продуктовые адаптации; художественные произведения не доказывают техническую
осуществимость и не являются спецификацией безопасности.

| Референс | Идея для PersAI | Реалистичный первый шаг |
| --- | --- | --- |
| Nextcloud Assistant [R20] | Работа с личными файлами и разными видами контента в одном месте | Связать оригиналы, транскрипты и поиск; выбирать модель по задаче |
| Home Assistant Assist [R16] | Общий каталог возможностей подключённых устройств | Показывать только явно разрешённые действия и подтверждать фактический результат |
| J.A.R.V.I.S., Marvel [R21] | Единый помощник для информации и действий | Утренняя сводка из календаря, почты и выбранных напоминаний; без автономных необратимых действий |
| Универсальный переводчик, Star Trek [R22] | Работа с голосом и языками | Перевод выбранного аудиофрагмента с сохранением оригинала и пометкой качества |
| «Автостопом по галактике», Дуглас Адамс [R23] | Карманный контекстный справочник | Пакет для поездки: выбранные сведения и списки доступны offline, источники и свежесть видны |

Из этих идей сначала стоит проверить «подготовь к встрече», «найди нужный фрагмент
моего видео», «собери покупки из выбранных рецептов» и «покажи, что требует внимания
сегодня». Постоянное прослушивание/тотальная запись жизни не входят в предложение.

## Исследовательские проверки перед выпуском адаптера

1. Подключение на тестовом аккаунте с минимальными правами, отзыв и повторный вход.
2. Read-only запрос, реальное изменение только тестового объекта, чтение результата.
3. Таймаут после успешной записи, повтор, пагинация, quota/429, offline и отмена.
4. Несколько аккаунтов: исключить использование не того календаря/папки/ящика.
5. Противодействие инструкциям из писем/страниц и чрезмерным схемам MCP; бюджеты данных.
6. Замер времени и полной цены, проверка на телефоне и в нужном регионе. Доступность
   сайта документации не подтверждает доступность API или способа оплаты.
7. Документированный fallback, отключение и удаление токенов/кэша.
