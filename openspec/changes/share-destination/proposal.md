# №61в: Android Share → чат или память

26.10.2026. Реализация утверждённого в #127 контракта, после объединённых #125–126. Benchmark N/A: точная реализация уже согласованного сценария; используются Nebula-токены и стандартная stack-навигация Android. Внутренние скрепка, камера и импорт не получают промежуточного вопроса.

## Поведение

Системное «Поделиться → PersAI» после разблокировки открывает компактную страницу: краткий материал, «В чат», «В память», Отмена/системный Back. URL не разрешается и не скачивается. Пока страница выбора или входящий импорт открыты, следующий intent остаётся в очереди Expo, не перекрывает текущий. После закрытия первый intent не воспроизводится повторно.

«В чат»: проверка возможностей до выбора; добавление файлов и текста/URL к существующему черновику одной операцией. Прежние текст/файлы не затираются. Ни вызова модели, ни заметки. Если текущий диалог занят, недоступен или совместный черновик превысит лимит, кнопка недоступна с объяснением. При нажатии проверки повторяются; повторный tap не дублирует добавление. Переход на Главную использует существующую навигацию: защита несохранённых редакторов остаётся действующей.

«В память»: замена chooser существующим предпросмотром новой заметки, сохранение только отдельной кнопкой. Несколько Share-элементов идут по существующему последовательному импорту; этот PR не объединяет их молча в одну запись. Добавление к существующей заметке остаётся внутренним действием #125.

## Матрица

| Материал | Чат | Новая заметка |
|---|---|---|
| Текст/URL | Дополняет текст черновика; вместе ≤24 000 символов | Текущий предпросмотр; ≤60 000 символов на элемент |
| JPEG/PNG/WebP | До 3 файлов по 2 МБ с учётом черновика; проверка сигнатуры | Существующий импорт оригинала |
| Текст UTF-8/JSON | Проверка чтения; содержимое файлов суммарно ≤24 000 символов | Существующий импорт при распознанном типе |
| Аудио/видео/GIF | Недоступно с объяснением | Существующий импорт поддерживаемого типа |
| PDF | Недоступно | В текущем создании заметки не поддержан; PDF доступен через добавление к существующей заметке |
| Неизвестный бинарный формат/remote file URI | Не перенаправлять молча | Отказ либо объяснение текущих ограничений |

На внешнюю группу ≤30 элементов. Модель/runtime №83 и Telegram/MAX MSG не изменяются. Лимиты чата/памяти не повышаются.

## Файлы и жизненный цикл

MIME/число/доступные размеры проверяются до выбора. Для допустимого чат-файла создаётся собственная копия в app-private cache, затем проверяются фактический размер/содержимое через общий reader скрепки. В `finally` удаляются только наши копии; исходный URI не удаляется. URL не передаётся resolver. Приватные URI не входят в сообщения ошибок.

Подготовка отменяется при уходе/блокировке/смене профиля; поздний результат не применяется. В памяти исправлена связанная утечка частично скопированного Share-файла: удаление и при ошибке, и после позднего завершения копирования, и при блокировке/уходе. Постоянные данные остаются в существующем SQLCipher, без новой схемы.

## Проверки и ограничения доказательств

Jest: обе кнопки, отсутствие автоматической мутации, повторный tap, блокировка/unmount, смешанные материалы, число/размер/кодировка, отказ URI, очистка частичных копий, атомарное дополнение черновика и отказ при смене текущего чата. Browser использует настоящий navigator/экран/store и адаптер системного intent: URL+файл → черновик, неподдерживаемый чат, Отмена, память → предпросмотр без автосохранения. Синтетические снимки: docs/design/references/share-destination-20261026/.

Нативные ACTION_SEND/ACTION_SEND_MULTIPLE от реальной галереи/файлов/браузера, URI grants, TalkBack и масштаб шрифта на физическом телефоне NOT RUN локально. Это остаётся наблюдениями по мере использования; отдельное подтверждение владельца не блокирует работу. Required minimal Maestro не расширялся.
