# Задачи

## 1. Зависимости (после SDK 57)
- [x] 1.1 `react-native-executorch` 0.10.5, `react-native-worklets` 0.10.1, `react-native-blob-util` 0.24, `react-native-audio-api` 0.13.6 (запись 16 кГц), `expo-build-properties`; в сборке только бэкенды XNNPACK и Core ML (без OpenCV, Vulkan, MLX)
- [x] 1.2 Микрофон: `RECORD_AUDIO` уже даёт плагин `expo-speech-recognition`; плагин `react-native-audio-api` не подключён, чтобы не добавлять фоновую службу; `minSdkVersion` 26, iOS 17
- [x] 1.3 Анонимная статистика загрузок библиотеки выключена (`setTelemetryEnabled(false)`)

## 2. Модель
- [x] 2.1 Блок «Голос без интернета» в настройках: Whisper base (около 400 МБ, рекомендуется) или tiny (около 150 МБ), прогресс, отмена, замена, удаление. Small (около 1,1 ГБ) не предлагается — слишком велик для телефона
- [x] 2.2 Скачивание только по нажатию, с предупреждением о размере и совете скачивать по Wi-Fi
- [x] 2.3 Целостность и докачку обеспечивает загрузчик библиотеки; при замене модели старые файлы удаляются
- [ ] 2.4 Определять Wi-Fi и предупреждать только в мобильной сети

## 3. Распознавание
- [x] 3.1 `VoiceInput`: своя модель → распознавание телефона → системная служба с согласием; без Google и без модели сообщение ведёт в «Голос без интернета»
- [x] 3.2 Потоковый текст в поле ввода (`stream` / `streamInsert` / `streamStop`), «Стоп» дописывает последнюю фразу, ограничение 60 с, приведение звука к 16 кГц
- [x] 3.3 Точные ошибки: нет модели, нет места, нет связи с huggingface.co, нет памяти, микрофон занят, модель занята

## 4. Проверка
- [x] 4.1 Тесты: поддержка платформ, передискретизация, тексты ошибок, путь через Whisper в `VoiceInput`, подсказка без Google
- [ ] 4.2 Замер на телефоне: задержка первого слова, скорость, точность на 20 фразах — base и tiny
- [x] 4.3 Шаги в `docs/DEVICE_QA.md`; требования перенесутся в `openspec/specs/voice-input` после приёмки на телефоне
