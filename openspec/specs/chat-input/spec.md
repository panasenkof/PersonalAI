# Ввод сообщения и подсказки

## Requirements

### Requirement: Очистка черновика
Система SHALL показывать крестик внутри непустого поля сообщения, включая пробельный текст.

#### Scenario: Очистка
- **WHEN** пользователь нажал крестик
- **THEN** весь черновик удалён, фокус остаётся в поле, крестик скрывается; история сообщений не меняется

### Requirement: Подсказки рядом с действием
Система SHALL показывать подсказку рядом с соответствующей кнопкой на Android и iOS, не создавая системный Toast или окно: по удержанию — всегда, по обычному нажатию — один раз за сеанс приложения для каждого действия.

#### Scenario: Повторное нажатие
- **WHEN** пользователь снова нажал «Отправить», подсказку которого уже видел в этом сеансе
- **THEN** действие выполняется без подсказки; удержание по-прежнему показывает её

#### Scenario: Кнопка внизу экрана
- **WHEN** пользователь нажал «Голос» или «Отправить»
- **THEN** пояснение находится над кнопкой и не перехватывает нажатия

#### Scenario: Верхняя панель
- **WHEN** пользователь нажал «Новый чат»
- **THEN** действие выполняется и подсказка видна под кнопкой, поверх содержимого чата

#### Scenario: Несколько нажатий
- **WHEN** пользователь запросил другую подсказку
- **THEN** предыдущая скрывается; новая поясняет нажатое действие и исчезает через 2,5 секунды после последнего запроса
