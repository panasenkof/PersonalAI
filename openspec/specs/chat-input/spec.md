# Ввод сообщения и подсказки

## Requirements

### Requirement: Улучшение черновика вручную
На главной система SHALL показывать «Улучшить» рядом с микрофоном. Только нажатие
запускает обработку всего текущего черновика через служебную LLM выбранного
подключения, без инструментов, памяти, истории или отправки сообщения. Автоматическая
обработка после диктовки и отдельная настройка не вводятся. Во время диктовки,
подготовки микрофона или ожидания последней фразы улучшение недоступно.

#### Scenario: Исправление и возврат
- **WHEN** модель вернула допустимое исправление
- **THEN** оно заменяет черновик; кнопка «Исходный» возвращает точный оригинал,
  включая пробелы; следующее «Улучшить» показывает сохранённое исправление без
  нового запроса. При отсутствии изменений видно пояснение

#### Scenario: Ошибка и пределы
- **WHEN** исходный текст длиннее 4000 символов, модель недоступна, ответ обрезан,
  не соответствует JSON-контракту, меняет записанные цифрами числа или защищённые
  отрицания
- **THEN** черновик не обрезается и не заменяется; видна причина. За одно нажатие
  допускается один запрос, не дольше 20 секунд, до 4000 токенов ответа, без
  автоматических повторов. Эти проверки не гарантируют сохранность всего смысла

#### Scenario: Отмена и изменение ввода
- **WHEN** пользователь нажал «Отмена» во время улучшения, начал новую диктовку,
  отредактировал/очистил/отправил черновик либо выбрал другой диалог
- **THEN** запрос отменяется, прежняя пара версий сбрасывается, поздний результат
  не изменяет актуальный текст, в том числе после возврата в прежний диалог

#### Scenario: Наблюдаемость
- **WHEN** включена диагностика
- **THEN** журнал содержит начало, результат/ошибку, длительность, версию промпта
  и события служебного запроса; исходный и исправленный тексты записываются только
  при отдельном включении содержимого

### Requirement: Очистка черновика
Система SHALL показывать крестик внутри непустого поля сообщения, включая пробельный текст.

#### Scenario: Очистка
- **WHEN** пользователь нажал крестик
- **THEN** весь черновик удалён, фокус остаётся в поле, крестик скрывается; история сообщений не меняется

### Requirement: Подсказки рядом с действием
Система SHALL показывать подсказку рядом с соответствующей кнопкой на Android и iOS, не создавая системный Toast или окно: по удержанию — всегда, по обычному нажатию — один раз за сеанс приложения для каждого действия.

#### Scenario: Повторное нажатие
- **WHEN** пользователь снова нажал «Отправить», подсказку которого уже видел в этом сеансе
- **THEN** действие выполняется без подсказки; удержание по-прежнему показывает её

#### Scenario: Кнопка внизу экрана
- **WHEN** пользователь нажал «Голос» или «Отправить»
- **THEN** пояснение находится над кнопкой и не перехватывает нажатия

#### Scenario: Верхняя панель
- **WHEN** пользователь нажал «Новый чат»
- **THEN** действие выполняется и подсказка видна под кнопкой, поверх содержимого чата

#### Scenario: Несколько нажатий
- **WHEN** пользователь запросил другую подсказку
- **THEN** предыдущая скрывается; новая поясняет нажатое действие и исчезает через 2,5 секунды после последнего запроса
