# Запросы к модели

## Purpose
Как приложение обращается к выбранной модели: протоколы, поток, пределы, ошибки.

## Requirements

### Requirement: Ограничения по времени
Система SHALL прерывать запрос, если заголовки ответа не пришли за 25 секунд, если во время потока 60 секунд нет данных (180 секунд у моделей с рассуждением) или если ответ длится дольше 4 минут (6 минут).

#### Scenario: Сервис недоступен из сети
- **WHEN** сервер не прислал заголовки за 25 секунд
- **THEN** ход завершается ошибкой «<адрес>: сервер не ответил за 25 с — подключение не установилось…»

### Requirement: Точная причина ошибки
Система SHALL называть в ошибке адрес сервера и причину: DNS, отказ в подключении, сертификат, нет сети, запрет `http://`, обрыв, тишина, предел времени или статус HTTP простыми словами с кодом провайдера, удаляя из текста ключ API.

#### Scenario: Сервис недоступен в регионе
- **WHEN** провайдер ответил HTTP 403 с кодом `unsupported_country_region_territory`
- **THEN** ошибка говорит «сервис недоступен в вашей стране или регионе (HTTP 403)» и приводит код

### Requirement: Потоковый ответ
Система SHALL показывать ответ по мере написания для OpenAI Responses, Chat Completions и Anthropic Messages и показывать этап: подключение, «модель думает», «пишет ответ», с временем ожидания.

#### Scenario: Сервер не поддерживает поток
- **WHEN** совместимый сервер отклонил параметр `stream`
- **THEN** запрос один раз повторяется без потока

### Requirement: Параметры моделей с рассуждением
Система SHALL отправлять `reasoning.encrypted_content` только моделям o-серии, gpt-5 и codex и сохранять ответ, обрезанный пределом длины, с пометкой.

#### Scenario: Модель без рассуждения
- **WHEN** выбрана `gpt-4.1-mini`
- **THEN** запрос не содержит `reasoning.encrypted_content`, предел ответа 4000 токенов
